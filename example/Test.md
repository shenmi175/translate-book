# 项目说明文档

## 1. 项目简介

这是一个用于测试 **Markdown 中英翻译格式保留能力** 的示例文档。  
目标是确保在翻译过程中，以下内容能够被正确保留：

- 标题层级
- **加粗文本**
- *斜体文本*
- 行内代码，如 `pip install requests`
- 列表与嵌套列表
- 引用块
- 表格
- 代码块
- 链接与图片说明
- 任务列表

---

## 2. 使用说明

请按照以下步骤操作：

1. 克隆项目仓库。
2. 安装依赖包。
3. 运行测试脚本。
4. 检查输出结果是否符合预期。

### 2.1 环境要求

- Python >= 3.10
- Node.js >= 18
- Git

### 2.2 安装命令

```bash
pip install -r requirements.txt
npm install
```

## 1. Project Overview

This is a sample document used to test **Markdown formatting preservation during Chinese-English translation**.  
The goal is to ensure that the following elements are preserved correctly during translation:

- Heading hierarchy
- **Bold text**
- *Italic text*
- Inline code, such as `pip install requests`
- Lists and nested lists
- Blockquotes
- Tables
- Code blocks
- Links and image descriptions
- Task lists
