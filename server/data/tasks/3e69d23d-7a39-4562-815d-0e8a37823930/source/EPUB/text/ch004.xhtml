编辑前言

F. A. 哈耶克文集的第一卷，其实是哈耶克生前最后写成的书——《致命的自负》。它在两个意义上都是第一卷：既是这一系列的第1卷，也是最早出版的卷（1988年出版）。首任总编辑是哲学家W. W. 巴特利三世（W. W. Bartley III），他最初设想整个系列会包含22卷——至少在《致命的自负》所附的系列计划说明中是这样写的。巴特利明智地补充了一句：“该计划是暂定的。”现在预计将共有19卷，但原来的附注依然有效。

自1988年以来，发生了许多事情。在巴特利的主编下出版的第二卷于1991年面世，但那已是遗作，因为巴特利于1990年2月因癌症去世。不久之后，斯蒂芬·克雷斯格（Stephen Kresge）接任总编辑，在他的主持下又出版了五卷。本系列的卷次并未按顺序出版：到目前为止，已出版的是第1、3、4、5、6、9和10卷。

2002年春天，斯蒂芬·克雷斯格问我是否有兴趣成为下一任总编辑。我答应了，在哈耶克家族以及芝加哥大学出版社和Routledge的代表们一致同意之后，我的工作就此展开。最初一年多的时间主要花在将编辑资料从加州转移到北卡罗来纳州，重新思考各卷的出版次序，建立与现有及潜在分卷编辑的联系，并寻求资金以支持这一项目。

《通向奴役之路：文本与文献——权威版》是我担任新任总编辑后推出的第一卷。其他卷也在筹备中。我预计未来几年会有相对稳定的进展，直至项目完成。

在第一卷中，比尔·巴特利曾简要说明本系列的编辑方针如下：“后续卷的文本将以修订、校正和附注的形式出版”；“那些存在轻微差异版本，或以多种语言存在的论文，将统一以英文或英文译本发表，且仅采用其最完整、最定稿的版本，除非某些差异或版本时间本身具有理论或历史上的重要性。”这些方针将在本卷及未来的卷中继续遵循。

关于《通向奴役之路》，我们作出了如下编辑决定。该书的英文本于1944年3月出版，美国版则于同年9月出版。美国版重新排版，主要是将“this country”一类的说法替换为“England”。因此，美国版在表达上更清晰（即它不假设读者知道“this country”指的是英国），所以我们选择以美国版为底本。因此，本卷全书均采用“美式英语”——在这一点上，本卷与该系列其他多以“英式英语”为底本的卷不同。印刷错误已被静默更正，除非是哈耶克提供了错误的引文。在这种情况下，改正会被注明。在书中许多地方，哈耶克引用了他人的话，但其引文并不总是与原文完全一致。然而，只有在误引可能影响段落含义时才会加以标注；无论如何，仍以哈耶克当时所写为准。

本系列的每一卷都旨在对哈耶克的著作做出权威性的呈现。因此，当芝加哥大学出版社建议我们在副标题中加上“权威版（The Definitive Edition）”时，我最初有所抗拒，认为这样似乎不妥，会把这一卷从其他卷中单独拎出来。但《通向奴役之路》确有特殊之处：它是哈耶克作品中唯一一部经历过多次版本修订的书——1944年原版，1956年版中哈耶克增添了前言，1976年版又加了新版前言，1994年五十周年纪念版则附有米尔顿·弗里德曼的导言。因此最终我们加上了这一副标题，我也希望它始终能被视为《通向奴役之路》的权威版本。然而，历史告诉我们，这或许不会是最后的一个版本。

在我作为新任总编辑开展工作的过程中，许多人给予了帮助。我特别要感谢小石城莫里斯基金会的多萝西·莫里斯女士，她提供了“启动资金”，使我能着手寻找该项目的更多资助。如同在此前各卷前言中所记载的那样，多萝西的丈夫沃尔特·莫里斯在《哈耶克文集》的创立过程中发挥了关键作用，而莫里斯基金会多年来始终给予支持。2002年10月，我在伦敦的蒙特佩勒林学会会议上首次寻求资金支持，经济事务研究所（IEA）的约翰·布伦德尔给了我不少建议，并帮助我获得了一份奖学金以抵消参会的费用。此次会议最终让我结识了埃尔哈特基金会的大卫·肯尼迪和英格丽·格雷格，以及自由基金会和皮埃尔·F.与伊尼德·古德里奇基金会的埃米利奥·帕切科。这些机构为该项目提供了主要资助。最后，斯蒂芬·克雷斯格在这场从第二任到第三任总编辑的漫长过渡中，以及之后的日子里，一直是我的顾问、导师、讨论伙伴和朋友。对他们所有人，我致以最真挚的谢意。

我还要感谢以下人士和机构，允许我们引用资料和信件：弗兰克·B. 奈特先生，允许我们刊载他为《通向奴役之路》所写的读者报告；托马斯·马沙克博士，允许我们刊载雅各布·马沙克的读者报告；大卫·迈克利斯先生，允许我们引用奥德韦·蒂德于1943年9月25日致弗里茨·马赫卢普的信件；以及胡佛战争、革命与和平研究所，允许我们引用其档案中的资料。

最后但同样重要的是，我要衷心感谢艾米丽·威尔科克斯和杰森·申克尔，他们在准备手稿过程中给予了帮助。

布鲁斯·考德威尔
北卡罗来纳州格林斯伯勒
