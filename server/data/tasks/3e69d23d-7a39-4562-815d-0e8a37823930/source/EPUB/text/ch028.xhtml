致谢

我要感谢北卡罗来纳大学格林斯伯勒分校（UNC-Greensboro）杰克逊图书馆馆际互借部门的工作人员，他们为我获取了大量书籍和文章供我使用。同时感谢参考馆员马克·舒马赫（Mark Schumacher），他帮助我查找了哈耶克一些较为晦涩的引用。还有许多人也在这项工作中给予了帮助，其中包括：杰克·布拉德尔（Jack Bladel）、瓦莱丽·考什梅兹（Valerie Cauchemez）、安德鲁·法兰特（Andrew Farrant）、温杜拉·克林克斯特罗姆伯爵夫人（Wendula Gräfin v. Klinckowstroem）、罗布·伦纳德（Rob Leonard）、哈罗·马斯（Harro Maas）、克里斯·泰姆（Chris Tame）、尤里·图卢彭科（Yuri Tulupenko）、维克托·范伯格（Viktor Vanberg）以及约翰·韦布（John Webb）。唐纳德·莫格里奇（Donald Moggridge）纠正了我导言中的一些错误。卡尔·施勒内斯（Karl Schleunes）、戴夫·林堡（Dave Limburg）以及蒂姆·威廉姆斯（Tim Williams）帮助我翻译了一些德语短语。经济教育基金会的裘德·布朗谢（Jude Blanchett）为我提供了克罗斯韦尔·鲍文（Croswell Bowen）于1945年发表的一篇关于《通往奴役之路》“销售”的有趣文章。最后，我要感谢约翰·布伦德尔（John Blundell）、斯蒂芬·克雷斯格（Stephen Kresge）和斯图尔特·华纳（Stuart Warner），感谢他们与我关于哈耶克的多次交流，并给予我许多关于本书的宝贵建议。

我特别感谢苏珊·豪森（Susan Howson），是她让我注意到哈耶克在威廉·贝弗里奇（William Beveridge）文稿中留下的备忘录，提供了伦敦政治经济学院（LSE）20世纪30年代的课程表，并提醒我注意马赫卢普文稿（Machlup collection）中哈耶克与马赫卢普的通信，这些信件远比哈耶克文稿中的要多。

我在杜克大学政治经济学研讨会、纽约大学的新自由主义会议、英国思想史会议，以及经济学史学会和澳大利亚经济思想史学会的会议上，先后展示过我导言的不同版本，并从与会者的意见中获益良多。芝加哥大学出版社的两位匿名审稿人指出了不少错误，并提出了改进手稿的建议。

芝加哥大学出版社的许多人在本书的准备过程中给予了我帮助。凯瑟琳·比比（Catherine Beebe）帮我在校档案馆中找到了相关资料，而我的编辑亚历克斯·施瓦茨（Alex Schwartz）则在无数细节上帮助我推动项目直至完成。

我最后一次见到哈耶克的儿子劳伦斯（Laurence）是在2004年6月剑桥大学国王学院（Kings College, Cambridge）举办的一次会议上，该会议纪念《通往奴役之路》出版六十周年。会议结束时，我们登上了国王学院礼拜堂的屋顶，参观了哈耶克和约翰·克拉帕姆（John Clapham）当年战时执行防空值勤的地方。劳伦斯曾是国王学院的学生，他显然很享受重温自己早年秘密登上礼拜堂屋顶的经历。仅仅三周后，2004年7月15日，劳伦斯·哈耶克在家中因心脏病突发去世。本卷谨以此献给他的记忆。

布鲁斯·考德威尔
