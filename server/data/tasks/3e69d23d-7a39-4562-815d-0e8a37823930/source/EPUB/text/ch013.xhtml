“计划”的“必然性”

我们首先宣称：文明的形态愈加复杂，个人的自由就必须愈加受限。
——贝尼托·墨索里尼1
（通俗解释：社会越复杂，个人自由就得被压得越紧。）

一个发人深省的事实是：很少有计划者满足于声称中央计划是“可取的”。他们中的大多数断言，我们已无法选择，而是被我们无法控制的环境所迫，必须以计划取代竞争。人们刻意培植一种神话：我们之所以踏上新路，并非出于自由意志，而是因为技术变化“自发地”淘汰了竞争，而这种变化既不可逆，也不该被阻止。此类论证很少被充分展开——它常常只是一些作者彼此转述的断言，因一再重复而渐被当作既成事实接受。然而，这种说法并无根据。走向垄断与计划的倾向，并非超出我们控制的什么“客观事实”的结果，而是半个世纪以来被扶植并传播的观念之产物，直至这些观念主宰了我们的全部政策。

诸多用以证明计划“不可避免”的论据之中，最常听到的一条是：技术变迁已使越来越多领域的竞争变为不可能，而我们仅剩的选择，要么是私人垄断控制生产，要么是政府主导。此一信念主要源自马克思主义“产业集中”的学说，不过，像许多马克思主义观念一样，它如今在许多圈子里流行，这些圈子第三手、第四手地接受了它，却不知其所自来。

在过去五十年中，垄断逐步增长、竞争统治的领域日益缩小，这一历史事实当然无可争辩——尽管这种现象的范围常常被极大夸大。2 关键问题在于：这发展究竟是技术进步的必然产物，还是仅仅是大多数国家所奉行政策的结果。我们不久即会看到，事实的发展史强烈地指向后者。但首先，我们得考察，现代技术变迁在多大程度上会使大范围的垄断增长变得不可避免。

所谓“技术导致垄断增长”的根据，是大企业相较小企业的优越性，缘由在于现代大规模生产方式的较高效率。有人主张，现代方法在多数产业中创造了这样的条件：扩大大企业的产量，其单位成本反而下降，于是大企业无处不在地压低价格、挤垮小企业；这一过程必将持续，直至每个行业只剩一家或至多几家巨头。此论证挑出技术进步偶尔伴随的一个效应，却忽略了沿相反方向作用的其他因素；而认真研究事实也鲜能支持这种说法。我们不能在此详加考证，只能满足于所能得到的最好证据。近时最为全面的事实研究，是美国“国会临时国家经济委员会（TNEC）”关于经济力量集中的调查。该委员会的最后报告（它当然不可能被指为过度偏向自由主义）得出的结论是：认为“大规模生产更高效率导致竞争消失”的观点，“在现有证据中几乎得不到支持”。3 委员会为此专门撰写的详尽专著亦如此总结：

“尚无证据证明大型企业在效率上占优；那些被认为足以摧毁竞争的优势，在许多领域并未显现。即便存在规模经济，也并非必然要求垄断……达到最优效率的规模可能远在供应的大部分被置于此类控制之下之前就已实现。关于‘大规模生产的优势必然导致竞争被废除’的结论，不能接受。还应注意，垄断往往源于低成本以外的因素。它通过串通协议达成，并受公共政策推动。当这些协议失效、这些政策被逆转时，竞争条件可以恢复。”4

对英格兰状况的调查会得出极为相似的结果。凡观察过那些踌躇满志的垄断者如何经常寻求、且往往获得国家权力之援助以使其控制有效的人，都难以怀疑这一发展并无必然性。

这一结论，还得到各国竞争衰落、垄断增长在时间顺序上所呈现的历史事实的有力支持。若这些现象是技术发展的结果，或是“资本主义”演进的必然产物，我们理应预期它们首先出现在经济体系最先进的国家。事实上，它们首先出现在十九世纪最后三分之一时期、当时尚属较年轻的工业国家——美国与德国。尤其在德国，这个后来被视为“资本主义必然演化”之典型的国家，自1878年起，政府便以有意的政策系统性地扶植卡特尔与辛迪加的成长。各级政府不仅运用保护主义这一工具，甚至提供直接诱因，并最终施加强制，以推动为调节价格与销售而形成的垄断。在这里，借助国家之手，关于“科学的计划”与“自觉的产业组织”的第一次大实验，催生了巨型垄断；五十年前，那里就已把这些垄断描绘为“不可避免的成长”，远在英国出现同样说法之前。正是在德国社会主义理论家（尤其是宗巴特）的影响下——他们从本国经验出发加以概括——“竞争体系向‘垄断资本主义’之不可避免发展”才被广泛接受。5 而在美国，高度保护主义亦促成了类似的发展，似乎进一步印证了此种概括。然而，与其说美国，不如说德国更被视为“普遍趋势”的代表；以至于人们常把德国称作——引一篇广为阅读的政论的说法——“所有现代文明的社会与政治力量都达到最先进形态的国家”。6

若考察英国1931年之前的状况，以及自该年起大不列颠亦踏上普遍保护之路后的发展，就会明白：其中“偶然性”何其少、“政策选择”之作用何其大。7 仅在十余年前，除少数较早获得保护的行业外，英国工业整体上仍大体像其历史上任何时期一样富于竞争。尽管二十年代在工资与货币政策彼此不相容的双重影响下备受折磨，但至少直至1929年的那些年，在就业与总体景气方面，并不逊于三十年代。也正是在转向保护主义、并伴随英国经济政策全面变更之后，垄断的增长才以惊人速度推进，将英国工业改造到公众迄今几乎尚未充分认识的程度。若有人辩称此发展与这一时期的技术进步有关，或说那些在1880至1890年代在德国起作用的“技术必然性”在1930年代才传到英国，这主张并不比另一种荒唐说法更有道理——那就是墨索里尼所暗示的：意大利之所以必须先于其他欧洲民族废除个人自由，是因为它的文明远远领先于他国！

就英格兰而言，说“舆论与政策的变化不过是在事实不可抗力之下的被动跟随”，或许还能造出几分貌似真实的外观，理由是这个国家常常在思想上步他国之后尘。于是可以争辩：产业的垄断化是在公众仍偏好竞争的情况下发展起来的，但外部事件挫败了他们的愿望。然而，一旦我们回望这一发展之原型——德国，理论与实践的真实关系便清晰可见。无疑，在那里，“压制竞争”是有意的政策选择，为的是追求我们今日所称“计划”的理想。在向“完全计划化社会”渐进的过程中，德国人与效法其样板的一切民族，不过是在遵循十九世纪思想家（尤其是德国人）为他们绘制的路线。过去六十到八十年的思想史，正是这样一个完美的例证：在社会演进中，“必然”的并非事实本身，而是“人们之思想使之成为必然”。

断言“现代技术进步使计划不可避免”，亦可被另一种方式理解：这可能意味着，我们现代工业文明的复杂性带来了新的问题，除了中央计划，我们别无有效应对之道。从某种意义上说，这话没错——但绝非其所声称的广义。例如，一个现代城市所造成的许多问题，像许多由空间高度邻近所引发的问题一样，靠竞争并不能得到充分解决。但那些援引“现代文明之复杂性”以为中央计划辩护的人，心头所想的并不是这类问题（如“公共事业”等）。他们通常暗示的是：要想把握整个经济过程的连贯图景日益困难，若不由某个中央机关来加以统筹协调，社会生活就会解体为混乱。

这种论点完全误解了竞争的运作。竞争不仅并非只适用于相对简单的条件，恰恰相反，正是现代条件下劳动分工的高度复杂性，使竞争成为唯一能够充分实现这种协调的方法。若条件足够简单，以至于一个人或一个委员会能够有效把握所有相关事实，那么实现有效控制或计划便毫无困难。唯有在必须考虑的因素多到不可能获得其总览之时，分散化才会成为必要；而一旦分散化不可避免，便会出现“协调”的问题——这种协调既要让各个单元能够依据只有它们自己才知道的事实，自主调整其活动；又要促成它们各自计划之间的相互调适。既然分散化之所以必要，正因为无人能够有意识地权衡影响众多个人决策的全部考量，那么，这种协调显然不可能靠“有意识的控制”来实现，而只能依赖某种安排，把他必须掌握的信息传递给每一位行动者，使其能有效地将自身决定与他人的决定相协调。由于影响不同商品供需条件的各种变动的细节，永远不可能被任何一个中心完全知晓，或足够迅速地收集与传播，我们所需要的，乃是某种“登记装置”：它能自动记录个体行动的一切相关效应，而其指示同时既是所有个体决策的合成结果，又是它们的行动指南。

这正是竞争条件下“价格体系”所做的事情——而其他任何体系甚至不曾许诺能做到这一点。价格体系使企业家能够通过观察寥寥几个价格的变动，像工程师盯住几只表针那样，把自己的活动与他人的活动相协调。关键在于：唯有在竞争盛行时（即个别生产者必须适应价格变化、而不能操纵价格时），价格体系才能履行此功能。整体越复杂，我们对个人之间“知识的分工”之倚赖就越深；而这分散的知识，正是通过我们称之为“价格体系”的非人格化信息传导机制，被协调成整体行动。

毫不夸张地说：若我们不得不依赖“有意识的中央计划”来推动工业体系的发展，它绝不可能达到今日这样的分化、复杂与灵活。与这种凭“分散化+自动协调”解决经济问题的方法相比，那种更显而易见的中央指挥方式可谓笨拙至极、原始而且局限。现代文明之赖以可能的劳动分工之深度，归功于一个事实：它并非必须靠有意识的创制才能达成；而是人类“偶然撞见”了一种方法，使劳动分工能够扩展到远超“计划所能及”的疆界。因而，复杂性的进一步增长，并非使中央指挥更为必要；恰恰相反，它使我们比以往任何时候都更需要运用一种“不依赖有意识控制”的技术。

还有一种理论，把垄断的增长与技术进步联系起来，其使用的论据几乎与前述相反；尽管鲜有清晰表述，它同样产生了相当影响。该理论并不主张“现代技术摧毁竞争”，而是说：恰恰相反，若不赋予免受竞争之保护（即授予垄断），许多新技术的可能性将无法被利用。此类论证并非必定虚伪，尽管警惕的读者也许会这样怀疑：那条显而易见的反驳——“如果满足我们需求的新技术真的更好，它就应能经受住竞争”——并不能处理所有被该论证指向的情况。不错，在许多情形里，这不过是利益相关方的特殊辩护。更常见的，或许是把“狭义工程学视角中的技术卓越”，与“从整个社会角度衡量的可取性”混为一谈。

然而，仍有一组情形，这种论点不无力量。比如，完全可以设想：如果强制英格兰所有人都使用同一种车型，那么英国汽车业也许能供给比昔日美国更便宜也更好的汽车；又或者，如果能强迫人人只用电，那么在所有用途上使用电，可能会比使用煤或煤气更便宜。在这类情形中，至少存在一种可能：若我们能自由选择，也许大家都会更好，且更愿意选择这种新局面——但事实是，没有任何“个体”得到这种选择权，因为可供选择的只有两种方案：要么我们“都使用”同一种廉价汽车（或“都只用”电），要么我们“保留选择权”，但每一样东西的价格都大幅提高。我不知道上述两例是否属实。但必须承认，有可能通过“强制标准化”或“禁止超过某个程度的多样化”，在某些领域里把“物质丰裕”提升到足以补偿消费者选择受限的程度。甚至可以想象，某一天出现这样一项新发明，人们一致认为其采用不容置疑地有利可图，但它的使用只有在许多人、乃至所有人“同时使用”的情况下才可行。

不论此类例子是否具有重大或持久的意义，它们无疑都不属于可以正当声称“技术进步使中央指挥不可避免”的情形。它们最多意味着：我们需要在“以强制手段获取某种特定好处”与“暂不获取该好处”（或在多数情形下，等进一步技术进步克服了特定难题后“稍晚获取”）之间作出抉择。确实，在此等场景下，我们也许必须为自由付出牺牲“眼前某种可能收益”的代价——但另一方面，我们由此避免了让未来发展受制于少数人当下知识的必要。通过放弃这类“可能的当下好处”，我们保存了推动进一步进步的重要刺激。虽然短期内，为了“多样性与选择自由”我们有时付出的代价会很高，但从长期看，即便就“物质进步”而言，这种进步也有赖于多样性本身，因为我们永远无法预见：某种商品或服务的诸多供给形式之中，究竟哪一种会孕育出更好的东西。当然，不能断言：凡是我们以牺牲当下物质舒适来换取自由的场合，最终都会得到回报。但为自由辩护正是要指出：我们应当为“不可预见的自由生长”留出空间。因此，即使在依据我们现有知识看来“强制似乎只有好处”的情形下，这个道理同样适用——哪怕在特定个案里，它或许并无害处。

在许多关于技术进步影响的现时讨论中，技术进步常被描述为某种“外在的东西”，仿佛它能强迫我们以某种特定方式使用新知识。诚然，发明给了我们巨大的力量；但说“我们必须用这种力量去毁掉我们最珍贵的遗产——自由”，却是荒谬的。这意味着：若我们想要保全自由，就必须比以往更警惕地守护它，并准备为它作出牺牲。虽然现代技术发展丝毫没有强迫我们走向“全面经济计划”，但它确实意味着：一旦有一个“计划当局”掌握权力，这种权力将变得危险无比。

既然几乎无可怀疑：走向计划的运动乃是有意识行动的结果，并不存在迫使我们如此的外在必然，那么值得追问的是：为何会有如此多的技术专家站在计划者的最前列？这一现象的解释，与一个批评计划者者也应时时铭记的重要事实紧密相关：几乎没有疑问，如果将实现他们的技术理想作为人类的唯一目标，那么他们几乎每一项技术理想都能在相对短时间内实现。我们认可且高度渴望的“美好事物”不胜枚举，也都“可能实现”；然而在有生之年，我们最多只能实现其中寥寥几项，或者只能很不完美地实现。正是他在本领域抱负的受挫，使专家反叛于现存秩序。眼见那些人人承认“既可欲、又可行”的事情得不到完成，我们都会难以释怀。而“这些事情不能同时全部完成、任何一项的达成都意味着牺牲其他项目”，只有把目光投向各专业之外的因素，经过痛苦的理性努力，方能察见——这种努力之所以痛苦，正因为它迫使我们把自己多数心力所系之对象，置于更广阔的背景下权衡，并把它们与我们眼前兴趣之外、因而我们更不在意的其他对象相比较。

在计划社会中，每一项单独考量即可实现的众多事情，都会造就一批为计划鼓与呼的“信徒”；他们自信，有能力把自己所重视的那个特定目标之重要性，灌注进此类社会的掌舵者的心中；而他们中的某些人确实会如愿，因为相较于当下，计划社会必定会更偏向于某些目标。否认我们所知的计划或半计划社会所提供的可取例证，当然是愚蠢的——那些国家的人民所拥有的某些“好东西”，的确完全归功于计划。德国与意大利的壮丽公路，常被举为事例——尽管修建此类道路同样完全可以在自由社会中实现。但以此类“特定领域的技术卓越”来证明“计划整体优越”，同样是愚蠢的。更为准确的说法是：当某一领域的极致技术卓越明显与总体条件不相称时，它反而证明了资源被误导。凡是驾驶过德国名路、却发现其车流量还不如英国不少次要公路的人，都会很难相信——就和平时期的用途而言——它们有多大正当性。至于这是否属于“计划者在‘枪炮’与‘黄油’之间做出选择”的场景，那是另一个问题。8 但按我们的标准，它们并不足以令人热情洋溢。

“专家的幻觉”，即他以为在计划社会中自己所珍视的目标会获得更多关注，这种现象比“专家”一词初听起来所暗示的更为普遍。就偏好与兴趣而言，我们人人都在某种意义上是“专家”。我们也都以为，自己的价值排序并非纯属个人口味；在理性人的自由讨论中，我们能说服他人承认“我们的排序才是正确的”。渴慕田园的人，最希望保持其传统风貌并清除工业在其美丽面容上留下的污点；注重健康的人，想把那些风景如画却不卫生的旧屋尽数拆除；驾车者，希望让乡间被宽阔的公路切割；迷恋效率的人，渴望把专业化与机械化推到极致；而理想主义者，为了人格的生长，希望尽可能多地保留独立手艺人——他们全都明白：自己的目标“唯有靠计划才能完全实现”，并且“正因如此他们都想要计划”。然而，当然，一旦采纳他们所呼吁的社会计划，那些被掩蔽的目标冲突就会原形毕露。

计划运动之所以有当下这般势力，很大程度上因为：就目前而言，计划仍主要是一种“抱负”，它把几乎所有“意志专一的理想主义者”、那些把一生奉献给单一事业的男男女女，汇聚在了一起。然而，他们寄望于计划，恰恰不是出于“兼顾全局的社会观”，而多半缘于“狭隘的视野”，乃至对某些他们置于首位的目标之重要性的巨大夸张。这绝不是低估这类人在我们这样的自由社会中的伟大现实价值——他们理应受到赞赏。但若让他们来计划社会，他们恰恰会成为“最危险的人”，也会成为“对他人的计划最不宽容的人”。从“圣洁而一心一意的理想主义者”到“狂热分子”，往往只有一步之遥。尽管“受挫专家的怨懑”为对计划的诉求提供了最强的推动力，但恐怕再没有比让各个领域里“最卓越的专家”在无人制衡的情形下实现其理想更令人难以忍受、也更不理性的世界了。所谓“协调”也不可能（如某些计划者所想）成为一门新的专门学问。经济学家是最不可能声称“自己拥有协调者所需知识”的人。他所呼吁的是一种方法：在无需一个“无所不知的独裁者”的情形下，仍能达成这样的协调。而这恰恰意味着：保留那些“非人格的、往往难以理解的”对个体努力的约束——而这正是所有专家都会不耐烦的东西。
