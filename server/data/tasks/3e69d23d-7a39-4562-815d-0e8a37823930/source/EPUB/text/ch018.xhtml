安全与自由

“整个社会将变成一个单一的办公室和一个单一的工厂，人人平等工作，人人平等报酬。”
——尼古拉·列宁（1917年）1

“在一个国家里，如果国家是唯一的雇主，那么反抗意味着被慢慢饿死。旧原则‘不劳动者不得食’，已被新的原则取代：‘不服从者不得食’。”
——列昂·托洛茨基（1937年）2

像虚假的“经济自由”一样，而且更有理由，经济安全常常被描绘为真正自由不可或缺的条件。从某种意义上说，这既是真实的，也是重要的。缺乏自信能够凭借自身努力闯出一条路的人，往往难以拥有独立的思想或坚强的性格。然而，经济安全的概念和本领域的其他许多术语一样，含义模糊、歧义丛生；正因如此，普遍支持追求安全的呼声可能反而成为自由的威胁。事实上，当“安全”被理解得过于绝对时，对其的普遍追求不仅不能增加自由的机会，反而会成为对自由最严重的威胁。

我们有必要一开始就区分两种不同的安全：一种是有限的安全，可以为所有人实现，因此它不是特权，而是合法的愿望；另一种是绝对的安全，在自由社会里不可能人人享有，因此也不应当作为特权被授予——除非在少数特殊情况下，如法官职位的完全独立至关重要时。这两种安全分别是：第一，对严重物质贫困的防护，即人人都能获得最低生活保障的确定性；第二，对特定生活水准的保障，或者说对某个人或群体相较于他人所享有的相对地位的保障。简而言之，前者是最低收入的保障，后者是某人被认为“应得”的特定收入的保障。我们将会看到，这一区分与另一种区分基本重合：即一类安全可以在市场体系之外、作为补充来普遍提供；而另一类安全只能为某些人提供，并且只能通过控制或废除市场来实现。

在像我们这样已达到一定财富水平的社会里，没有理由不为所有人保证第一种安全，而不危及整体的自由。虽然确切的最低标准如何界定是一个棘手问题，尤其是那些依赖社会保障的人是否应该无限期地享有与其他人完全相同的自由，这一点会引发重要的政治问题3，并且若处理不慎可能导致严重甚至危险的后果。但毫无疑问，可以为所有人保证最低限度的食物、住所和衣物，以维持健康和劳动能力。事实上，在英格兰，相当一部分人口早已获得了这种安全。

同样，没有理由不由国家来帮助个人应对那些由于不可预测性而难以由个人充分准备的生活风险。当面对疾病和意外时，既无意愿去遭受此类灾难，也无能力独自承担其后果，这类情况通常不会因救助的提供而削弱避免灾难或克服后果的努力。换言之，当我们处理的是完全可投保的风险时，国家帮助建立一个全面的社会保险体系的理由就非常充分。在此类制度的细节问题上，那些希望维护竞争体系的人和那些希望用别的体系来取而代之的人可能会有分歧；而且，确实有可能在“社会保险”的名义下引入一些措施，使竞争在不同程度上失效。但原则上，国家通过这种方式提供更多安全与维护个人自由之间并无不兼容之处。属于同类的还有国家对地震、洪水等“天灾”受害者的援助。凡是个体既无法预防、也无法为后果作准备的灾害，只要通过集体行动可以减轻，毫无疑问就应当由集体出手。

最后，还有一个至关重要的问题：如何应对经济活动的总体波动及其伴随而来的反复出现的大规模失业浪潮。这无疑是我们这个时代最严重、最紧迫的问题之一。但尽管其解决需要大量“良性意义上的计划”，却并不——至少不必然——需要那种倡导者所主张的、要取代市场的特殊计划。许多经济学家确实希望最终的解决办法能够在货币政策领域找到，而这与十九世纪自由主义也并无根本冲突。另一些人则认为，只有通过大规模的公共工程并恰当地把握时机，才能真正取得成功。4 这可能会导致对竞争领域更严重的限制；在这方面的尝试中，我们必须格外谨慎，避免让一切经济活动逐渐依赖于政府支出的方向和规模。但无论如何，应对这些波动的必要努力并不会导致那种真正威胁自由的计划模式。

旨在保障另一类安全的计划——正是这种对自由具有潜移默化侵蚀作用的安全——是为了保护个人或群体不因收入下降而受害，即便这种下降在竞争社会中每天都在发生、完全不是他们应得的。这种损失可能带来严重的痛苦，毫无道义上的正当性，却又是竞争制度不可分割的一部分。对这种安全的诉求，实际上就是对“公正报酬”的另一种呼喊——要求收入与个人的主观努力和优点相称，而不是与其客观成果挂钩。这类安全或正义的追求似乎与人们自由选择职业的权利无法调和。

在任何一个依靠个人自由选择来分配劳动力于不同行业和职业的制度中，薪酬必须与其对社会其他成员的有用性相符，即便这种有用性与个人的主观优点毫无关系。尽管在许多情况下，付出与结果可能大体相称，但这种情况在任何社会里都不可能总是成立，尤其在某些情境下更是如此：当某种行业或特殊技能的价值因不可预见的环境变化而骤然改变时，情况尤为明显。我们都知道那种受过高度训练的人，他凭借多年艰苦学习获得的技能，因一项发明使整个社会受益而突然失去了价值的悲惨处境。过去一百年的历史充满了这类例子，其中一些甚至波及数十万人。

毫无疑问，一个人尽管努力工作、技艺高超，却因完全无辜的原因而遭受收入骤减、希望破灭的打击，会触动我们的正义感。那些因此受害的人，要求国家出面干预以保障其“合理期待”，势必会赢得公众的同情和支持。政府普遍接受这些诉求的结果是，采取措施不仅保护这些人免受严重的贫困与苦难，还要确保他们继续领取原有的收入，把他们从市场的变动中庇护出来。5

然而，如果允许人们自由选择职业，那么为所有人提供固定收入的保障是不可能的。如果为部分人提供这种保障，那就必然成为某种特权，而这种特权是以削弱其他人的安全为代价的。事实很容易证明，只有在彻底废除职业选择自由的情况下，才能为所有人提供不变收入的安全。尽管如此，这种对“合理期待”普遍保障的理想常常被视为追求的目标，但却从未真正得到认真实施。政府一贯做的事情是零碎地把这种保障赋予某个群体或另一个群体，结果是，被排除在外的人反而感受到越来越多的不安定。难怪随着这种特权的价值不断上升，诉求也愈发急切，直到最后，自由的代价似乎也不算太高。

如果要保护那些因无法预见或控制的情势变化而丧失价值的人不遭受“不应得的损失”，同时阻止那些因同样的原因而价值上升的人获得“不应得的收益”，那么报酬很快就会失去与社会实际有用性之间的联系。它将取决于某个当局的主观看法：一个人本该做什么、本该预见什么、他的动机是好还是坏。这种判断必然在很大程度上带有任意性。其结果是，从事同样工作的不同人将会得到不同的报酬。这样一来，报酬差异就不再能对人们形成足够的激励去作出那些对社会有益的转变；而个人也无法判断，某个变化是否值得自己为之付出代价。

然而，如果社会中那些对劳动力在不同行业之间的必要调配，不再依靠报酬和惩罚（它们本来与主观优点并无必然关系），那么这种调配只能通过直接命令来实现。当一个人的收入被保证时，他既不能仅仅因为喜欢而继续留在某个岗位上，也不能自由选择想转去的工作。因为是否迁移、是否转岗所带来的损益已不再由他承担，决定就必须由掌控收入分配的人来做。

这里涉及的激励问题，通常被讨论得仿佛仅仅是人们是否愿意尽力的问题。诚然，这一点重要，但却不是问题的全部，甚至不是最重要的方面。更重要的是，如果我们希望人们能够自由选择、自己判断应当做什么，就必须为他们提供某种容易理解的尺度，以衡量不同行业对社会的价值。即便怀有最大的善意，如果各种选择的利益与其对社会的贡献毫无关系，人们也不可能做出理性的选择。要判断一个人是否应该放弃自己喜欢的行业和环境，转而从事另一份工作，就必须让这些职业对社会的相对价值通过报酬的差异表现出来。

当然，这个问题更为重要的原因是，在现实世界中，如果个人利益不直接相关，大多数人不大可能在长时间内保持最佳表现。至少对于大批人而言，需要有外在的压力来促使他们尽力而为。在普通劳动和管理活动领域，这种意义上的激励问题都是非常现实的。把工程学的技术应用于整个国家——而这正是计划的真正含义——“提出了极难解决的纪律问题”，正如一位在政府计划中拥有丰富经验的美国工程师敏锐地指出的那样，他已清晰地洞察到这一问题。

“为了完成一项工程任务，”他解释道，“工作周围必须有一个相对广阔的未被计划的经济活动区。必须有一个可以随时调配工人的地方，当工人被解雇时，他就应当从岗位和工资册上消失。如果缺乏这样一个自由的‘储备库’，那么纪律就无法维持，除非诉诸体罚，就像奴隶劳动那样。”6

在管理层工作的领域里，因疏忽而产生的惩罚问题以不同但同样严重的方式出现。有人曾精辟地说过，在竞争性经济中，最后的制裁是由执行债务的法警完成的，而在计划经济中，最终的制裁却是刽子手。7 在计划体制下，工厂经理必须被赋予相当大的权力。但与普通工人一样，经理的地位和收入也不能仅仅依赖于其管理工作成功与否。因为风险和收益都不再属于他，判断标准就不再是他的个人判断，而是他是否按照某种既定规则“应该”做的事。如果他犯下一个“本该”避免的错误，这就不仅是个人的过失，而是对社会的犯罪，必须如此对待。只要他走在那条客观可判定的“安全道路”上，他的收入或许比资本主义企业家更有保障；但一旦真正失败，等待他的威胁比破产还要严重。他的经济安全只能在满足上级时才存在，而这种安全是以牺牲自由与生命为代价换来的。

我们必须正视的冲突，实际上是两种完全不可调和的社会组织模式之间的冲突。这两种模式通常被称为商业型社会和军事型社会。或许这些术语并不恰当，因为它们容易把注意力引向枝节，使人难以看清我们面对的是一个真正的二选一局面，没有第三条路。要么个人既拥有选择权也承担风险，要么他被剥夺了两者。军队在很多方面最接近第二种模式：工作和工人都由权威分配，如果资源有限，每个人都同样被减量供给。这是唯一一种能够为个人提供完全经济安全的制度，若将其扩展至整个社会，就能让所有人都获得这种安全。然而，这种安全与自由的限制和军事生活的等级秩序密不可分——它是一种“兵营式的安全”。

当然，可以在一个总体自由的社会中，局部地建立这种体制。没有理由不让那些愿意接受这种带有限制的生活方式的人去选择它。实际上，一种军事化的自愿劳动服务，也许正是国家为所有人提供就业机会和最低收入保障的最佳形式。之所以过去此类提案鲜少被接受，是因为那些愿意为安全放弃自由的人，总是要求国家也把自由剥夺掉，不允许别人继续拥有。这种诉求实在难以找到正当理由。

然而，我们对军事体制的了解，还不足以想象若将其扩展至整个社会会是什么模样。当只有一部分社会按军事模式组织时，其成员的不自由还能因其余自由空间的存在而得到缓解，他们仍有可能转移到别处。如果我们真要描绘一个社会的全貌，即按照许多社会主义者所憧憬的理想，把社会组织成一个庞大的工厂，我们就必须回想古代的斯巴达，或者看看当代德国——在经历了两三代人的转变之后，它已接近这一目标。

在一个习惯于自由的社会里，恐怕没有多少人会愿意以这样的代价去换取安全。然而，当下各国普遍推行的政策——不断将安全的特权分发给这个群体、那个群体——却正在迅速营造一种环境，使得对安全的追求逐渐压倒了对自由的热爱。原因在于：每一次对某一群体授予绝对安全，都会必然增加其他人的不安全感。如果你保证某些人在一个可变的大蛋糕里获得固定的一份，那么留给其他人的部分就必然比整体波动更大。而竞争制度所提供的那种最核心的安全感——广泛的机会选择——正被不断削弱。

在市场体制下，安全只能通过所谓的“限制主义”来赋予特定群体（而这几乎涵盖了所有现实中实际推行的“计划”！）。所谓“控制”，也就是限制产量以确保价格能带来“合理”收益，这是市场经济中生产者获得固定收入的唯一途径。但这必然意味着机会对其他人被减少。如果某个生产者——无论是企业家还是工人——要被保护，不受外来竞争者压价的威胁，这就意味着那些境况更差的人被排斥在外，无法分享相对繁荣行业的收益。每一道进入行业的限制，都会降低所有局外人的安全感。随着这种保障收入的群体不断增加，任何失去收入的人可转向的替代机会范围也随之缩小；因此，受到不利变动影响的人避免收入严重下降的机会也相应减少。而如果，正如如今越来越普遍的情况一样，每当某个行业条件改善时，其成员都能阻止外人进入，以确保自身通过更高工资或利润独享全部收益，那么在那些需求下降的行业里，人们将无处可去，每一次变动都会造成大规模失业。毫无疑问，过去几十年失业人数和不安全感的显著增加，在很大程度上正是这种通过限制主义追求安全的结果。

在英格兰和美国，这类限制措施——尤其是那些影响社会中间阶层的措施——直到相对较近的时期才发展到相当的规模，而我们几乎还没有完全意识到它们的全部后果。在一个社会已经僵化、而某些人被排除在受保护职业之外时，他们所面临的彻底绝望，以及他们与那些幸运拥有职位者之间的鸿沟，只有亲身经历过的人才能真正体会。这并不是说幸运者必须放弃自己的岗位，而只是说他们应当通过降低部分收入，或者常常甚至仅仅是牺牲一些改善前景的机会，来共同分担社会的不幸。但他们所谓“生活水准”的保障、“公平价格”或“职业收入”的保障，却得到了国家的支持，从而阻止了这种分享。结果，如今不再是价格、工资和个人收入在发生剧烈波动，而是就业与生产本身成了剧烈波动的对象。人类历史上，从未有过比这种因“规范竞争”而使强势群体对弱势或不幸群体进行剥削更严重、更残酷的情况。“某些价格（或工资）的稳定化”这一口号，造成的危害巨大——它一方面确保了少数人的收入，另一方面却使其他人的处境越来越危险。

因此，我们越是通过干预市场体系来提供全面的安全，就越是加剧了普遍的不安全感；更糟糕的是，那些被授予安全作为特权的人与那些日益不安全的人之间的对比越来越尖锐。而随着安全日益成为特权，那些被排除在外者的危险越大，安全就越被人珍视。随着特权者人数的增加，他们的安全与他人的不安全之间的差距也随之扩大，社会便逐渐产生出一整套全新的价值体系。不再是独立决定了一个人的地位，而是安全；年轻人是否适合结婚，不在于他对自己前途的信心，而在于他是否拥有领取养老金的稳定权利；而不安全感则成为了如同贱民般的可怕境遇——那些在青年时期被拒之于有薪职位港湾之外的人，终其一生都只能困于这种境地。

这种由国家容忍或支持的、通过限制性措施追求安全的普遍努力，随着时间推移，已经导致社会发生了渐进的转型——在这种转型中，正如在许多其他方面一样，德国走在前列，其他国家则紧随其后。而这一发展过程，还被另一种社会主义教义的作用加速了：那就是对所有涉及经济风险的活动的刻意贬低，以及对使冒险值得去做的收益的道德谴责（尽管这种收益只有少数人能获得）。我们无法责怪年轻人偏爱安全的薪水职位而不愿冒险创业，因为他们从小听到的教育就是：前者更高尚、更无私、更值得尊敬。当代年轻一代成长在这样一个世界：在学校与报刊中，商业企业精神被描述为卑鄙，逐利行为被谴责为不道德，雇佣一百人被视为剥削，而指挥一百人却被认为光荣。年长者或许觉得这是对现实的夸大，但大学教师的日常经验几乎不留任何疑问：由于反资本主义的宣传，社会的价值观已经在很大程度上超前于制度变迁而发生了改变。问题在于，当我们为了满足这些新要求而改变制度时，是否会无意中毁灭那些我们依旧视为更高价值的东西。

安全战胜独立这一理想所引发的社会结构变化，最清楚的例证莫过于对十年或二十年前仍可被视为“英式社会”和“德式社会”的比较。无论军队在德国影响有多大，如果把英国人所称的“德国社会的军事性格”主要归因于军队的影响，都是严重的错误。差异要比这深刻得多：即便在那些军队影响微弱的领域，德国社会的特殊属性也同样存在。其独特性并非因为德国人民在任何时候都比其他国家更多地为战争组织起来，而是因为这种自上而下的组织形式被用于许多其他目的，这才赋予了德国社会特殊的性质。正是因为在德国，比任何其他国家更大比例的民众的日常生活被有意地自上而下组织起来，正是因为如此大比例的德国人不再将自己视为独立的人，而是视自己为某种被任命的职员，这才赋予了她的社会结构特殊的性格。德国，正如德国人自己所自豪宣称的，早已是一个“官僚国家（Beamtenstaat）”，在其中，不仅在狭义的公务员体系内，而且几乎在生活的各个领域，个人的收入和地位都由某种权威来分配和保障。8

虽然自由精神是否能被武力彻底根除仍然存疑，但没有任何把握能说，任何民族都能成功抵御那种在德国发生过的、被逐渐窒息的过程。在那里，几乎所有的区分与地位都依赖于成为国家的有薪仆役；在那里，履行被指派的职责被视为比选择自己认为有用的领域更值得称赞；在那里，凡是不能在官方等级体系中占有一席之地、或不能凭借固定收入获得保障的追求，都被视为低劣甚至有些不体面的。在这样的环境下，要求许多人长久地偏爱自由胜于安全，实在过于奢望。而当摆在面前的选择是：要么依附体制换取安全，要么处于极其不稳定的地位——在那里，无论成功还是失败都会同样遭到鄙视——那么，能抗拒以自由换安全诱惑的人必然寥寥无几。一旦发展到这种地步，自由几乎成了讽刺，因为它只能通过牺牲尘世间的大部分美好事物来换取。在这种境况下，人们越来越觉得：没有经济安全，自由便“不值得拥有”，因而愿意为安全牺牲自由，也就不足为奇了。但令人不安的是，哈罗德·拉斯基教授竟然也使用了这种论点——这种论点也许比其他任何理由更能解释为何德国人民会牺牲自由。9

毫无疑问，提供足够的保障以防止严重贫困，并减少那些可避免的、因努力方向错误而带来的失望，必须成为政策的主要目标之一。但如果这些努力要取得成功、而又不至于摧毁个人自由，那么安全必须在市场之外得到提供，而竞争则必须保持不受阻碍。一些程度的安全是维护自由的必要条件，因为大多数人愿意承担自由不可避免的风险，前提是风险不要过于巨大。这一事实我们绝不能忘记。但比这更致命的，是当下知识界领袖们盛行的风气：他们大肆吹捧安全，却以牺牲自由为代价。我们必须重新学会坦然面对这样一个事实：自由只能以代价换取，而我们作为个人必须愿意做出重大的物质牺牲来守护自由。如果我们要保有自由，就必须重新获得那种信念——正是这种信念支撑了英美国家的自由传统。富兰克林曾以一句话表达了这一点，这句话对个人生活与国家生活同样适用：“那些为了购买暂时的安全而放弃根本自由的人，不配享有自由，也不配享有安全。”10
