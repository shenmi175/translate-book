导言

没有什么发现比揭示观念的谱系更令人恼火的了。——阿克顿勋爵1

当代事件不同于历史之处在于：我们并不知道它们将产生何种结果。回望过去，我们可以评估既往事变之意义，并追溯其所带来的后果。然而，当历史正在行进时，于我们而言它尚非“历史”。它引领我们进入未知之境，而我们鲜有机会洞见前方将至的景象。若是我们得以带着既往所见的全部知识，再度经历同一段事件，情形便会迥然不同。许多我们如今几乎不以为意的变化，将显得何等重要，乃至令人忧惧！或许幸运的是，人不可能获得这种体验，也不知历史必须遵循何种法则。

然而，尽管历史从不原样重演，且也正因为没有任何发展是必然的，我们仍可在一定程度上从过去汲取教训，以免重蹈覆辙。要意识到迫近的危险，并非必须成为先知。经验与兴趣的偶然组合，常常会使某个人较他人更早在特定侧面下看见事势的端倪。

以下诸页，乃是一种尽可能接近“第二次活过同一时期”——或至少“第二次目睹一场极为相似之观念演化”的体验的产物。此等体验在一国之内不大可能获得，但在某些境遇下，若能先后在不同国家长期栖居，则或可获得。虽说多数学术国家中思想潮流所受之诸般影响在很大程度上相似，然而这些影响未必在同一时间、以同一速度发挥作用。于是，当人由此国迁往彼国，时常得以两度目击相似之思想发展阶段。届时诸感尤为敏锐：当人第二次听到那些二十或二十五年前首次遭遇的意见与主张时，它们便呈现出一种新意义，作为某种明确趋势的征候。2 它们提示我们，若非必然，亦至少很可能，发展将循类似轨道而行。

如今有必要直陈这令人不快的事实：我们正有重蹈德国覆辙之虞。固然，此危机并非迫近无间，而英美两国之现实状况与德国近年所见仍相距甚远，以致很难相信我们正在沿着同一路径前行。然而，哪怕道路漫长，人在其上前行越久，回头便越艰难。若说从长远看我们是自身命运的塑造者，那么在短期内，我们却是自己创造之观念的俘虏。惟有及时识得风险，方有望加以扭转。

英美两国眼下尚未与希特勒治下之德国——亦即当下之战时德国——相类。然则，凡研习思想潮流者几乎难以否认：德意志在上次大战期间及战后之思想走向，与今日诸民主国家之观念潮流之间，存在的不仅是表面的相似。今日在这些国家里，至少可以肯定地见到同一种决心：要将为国防之需而建立起来的国家组织保留用于“建设”的目的。也同样有对十九世纪自由主义的轻蔑；同样伪装为“现实主义”的论调，甚至犬儒；同样对所谓“不可避免趋势”的宿命式接受。而我们那些最善喧哗的改革者极力要我们从这场战争中汲取的教训，十之八九恰是德国人在上次大战后确然汲取的教训，而这些教训正促成了纳粹制度的产生。稍后我们将在本书中指出，在相距十五至二十五年的诸多方面，我们似乎正追随德国的前例。虽说人们并不乐于被提醒，但对至少前一代人而言，德国的政策与实践曾深刻影响英格兰的理想与政策，而在某种程度上也影响了美国；这距离今日并不算久远。近年瑞典如何被进步派视为典范，昔日德国的社会主义政策也曾被同样地仰视。

作者的成年岁月约有一半在故土奥地利度过，与德语世界的思想生活保持密切接触；另一半则在美国与英格兰度过。在后半段岁月里，作者愈发深信：至少部分摧毁德国自由之力量，同样在此间发挥作用；而这种危险之性质与来源，若非更甚于德国当年之状，亦至少同样不为人所明。至今仍未被看清的至上悲剧正在于：在德国，正是那些怀抱善意、且在诸民主国家为人钦佩并被奉为典范的人，铺就了——纵非亲手铸就——他们如今所憎恶之势力的道路。我们是否有望避免类似命运，取决于我们是否直面威胁，并准备在必要时修正——哪怕是我们最珍爱的——希望与雄心，若它们正是危机之源。迄今为止，几乎未见我们有承认自身可能有误的那种智识勇气的征兆。鲜有人愿意承认：法西斯主义与纳粹主义之崛起，并非对先前社会主义趋势的反动，反而是那些趋势的必然结果。即便当人们已广泛承认共产俄国与国家社会主义德国之内部体制在许多可憎特征上的相似，这一真相仍为多数人所不愿见。其结果是：自以为远高于纳粹癫狂、并真诚憎恨其一切表现的人，同时却为一些理想而努力，而这些理想一旦实现，将径直导向他们所憎恶的暴政。

当然，国别之间的类比总是具有迷惑性；但我的论证并非主要系于此类类比。我也并不主张这些发展是“必然”的——若果如此，写作本书便失去意义。只要人们能及时认识到自身努力可能导致何处，这些发展便可以避免。然而，直到近来，几乎看不到让人们看见危险的尝试能取得成功的希望。不过，如今似乎已是更全面讨论整个问题的良机。不仅因为问题已更为广泛地被认识，而且在此关节点上还有一些特殊原因，使我们不得不正面迎对这些问题。

或有人说，此刻并非提出此种意见分歧尖锐之议题的时机。然而，我们所论之社会主义并非党派之事，而我们所讨论的问题也与政党间争论的议题关联不大。某些集团要的社会主义较之他者为少；或某些人欲为此一集团之利而行社会主义、他者则为彼一集团之利；此等差异均无损于我们的问题。关键在于：若论那些影响发展之人物的观念，如今在诸民主国家，他们在某种意义上无不成了社会主义者。倘若“我们如今都是社会主义者”这句话已不再时髦，那不过是因为其事实过于显而易见。3 几乎无人质疑我们必须继续向社会主义迈进；大多数人不过是在努力使这股潮流偏转，以有利于某一特定阶级或群体。

正因为几乎人人所欲，我们才沿此方向前行。没有什么“客观事实”使之不可避免。关于所谓“计划”的必然性之辩，我们稍后将有所论及。眼下最要紧的问题是：此一运动将把我们引向何处？那些当下以其信念赋予这股潮流不可阻挡之动量的人，倘若开始看到——哪怕只是一少数人目前方能觉察的东西——他们是否会恐惧地退缩，从而放弃这场半个世纪来吸引了无数善意之士的追寻？我们这一代共同持有的信念将把我们带往何方，这是每一个人——而非某个政党——必须面对的重大问题。可曾有比这更大的悲剧？我们试图依据崇高理想自觉塑造未来，结果却不自觉地造就了我们竭力避免之物。

更为迫切的理由在于：此时若能认真理解催生国家社会主义的那些力量，便能理解我们的敌手以及我们与之对峙的实质问题。不可否认，我们迄今对自身所捍卫的积极理想之认识尚浅。我们知道我们在为自由而战——为按自己的观念塑造人生之自由而战。这固然意义非凡，但仍不足够。若要抵御一位将宣传作为主要武器之一、且不仅以最赤裸也以最隐微方式运用之的敌人，我们需要更为坚定的信念。尤其当我们必须在其控制之国度及其他地方对抗其宣传时，单有此点更为不足——在那里，此等宣传之效力并不会随着轴心国的战败而自然消散。若要向他人显示我们所捍卫之物值得他们支持，这还不够；若要引导我们建构一个免于旧世界所沦陷之危险的新世界，这也不够。

令人遗憾的是，战前民主国家在与独裁者打交道时与其后的宣传尝试，以及关于其战争目的的讨论中，表现出一种内在的不自信与目标上的不确定。这只能用他们对自身理想的困惑、以及对自己与敌人之间分歧之性质的混淆来解释。我们之被误导，既因为我们拒绝相信敌人真诚地宣称某些与我们相同的信念，也因为我们轻信他们在其他主张上的“真诚”。左派与右派岂非同样被“国家社会主义党是服务于资本家、反对一切社会主义”的说法所欺骗？希特勒体制中的多少特征未曾在最出人意料的角落被举荐给我们效仿，而此等举荐者却未意识到，那些特征乃是该体制不可分割之部分，与我们力图保全的自由社会根本不相容？战前与战后，我们因不了解面对之敌而犯下的危险错误之多，令人触目惊心。几乎就像我们不愿理解导致极权主义的历史进程——因为一旦理解，便可能摧毁我们执意固守的一些最可爱的幻念。

除非我们了解当今支配德国人的那些观念的性质与成长，我们在与德国人打交道上永不会成功。如今又有人提出那种论调，谓“德国人天性恶劣”。此论几不可立，持之者也难称光采。它抹杀了过去一百年来一长列英美思想家——他们欣然吸收了德国思想中的优长（乃至不止优长）——的功绩。它也忘却了：八十年前，约翰·斯图亚特·密尔写《论自由》这篇伟大论文时，其灵感更多地来源于两位德国人——歌德与威廉·冯·洪堡——而且两位对国家社会主义影响最深的思想先驱——托马斯·卡莱尔与休斯敦·斯图尔特·张伯伦——分别是一位苏格兰人与一位英国人。4 此种粗鄙版本的论调，是对持之者的一种污点，因为他们在维持它时采纳了德国人种论中最恶劣的特征。

问题不在于“德国人天生邪恶”——他们的天性恐怕并不比他族更为恶劣；真正的问题在于：在过去七十年间，何种情境使得一套特定观念得以渐进壮大并最终获胜；以及为何这场胜利最终让其中最恶劣的分子登临权力之巅。单纯仇恨“一切德国的东西”，而不是针对如今主导德国人的那些特定观念，尤为危险，因为它让沉溺其中者对真正威胁视而不见。此种态度恐怕常常不过是一种逃避：他们不愿承认一些并不局限于德国的趋势，也不愿重新审视并在必要时摒弃一些我们从德国承袭而来、如今仍像当年德国人一般受其蒙蔽的信念。此种态度更加危险之处在于：若谓纳粹制度仅乃“德国人之独特邪恶”的产物，此论极可能反过来成为把正是制造这种邪恶的制度强加于我们的借口。

本书所将提出的有关德意两国发展的解释，与多数外国观察者与多数彼地流亡者所给出的解释大相径庭。若此解释为真，亦可说明为何像大多数流亡者与英美报纸的外国记者那样，持当下流行的社会主义观念者几乎不可能以适当的视角来看待这些事件。那种肤浅而误导的看法，将国家社会主义仅仅视为那些既得利益或利益将受社会主义推进之威胁的人所煽动的“一种反动”，自然得到那些人之支持：他们曾经积极参与那股最终通向国家社会主义的观念潮流，但在某个阶段止步不前；于是他们与纳粹发生冲突，被迫离国。但他们在数量上成为对抗纳粹的唯一重要反对力量，只能说明在广义上几乎所有德国人都已成为社会主义者，而古典意义上的自由主义已被社会主义所驱逐。我们将力图表明，德国所谓民族社会主义“右翼”与“左翼”的冲突，乃是任何对立的社会主义派别之间都必然出现的那种冲突。若此解释为真，则意味着：许多社会主义流亡者在坚持其信念之时，虽出于最良善之意，却正在帮助其受国走上德国所曾走过的道路。

我知道，许多英美友人有时会被德国流亡者偶尔流露的“半法西斯式”观点所震惊，尽管这些人具有不容置疑的社会主义信念。可当旁观者把这归因于那“毕竟他们是德国人”之时，真实解释却是：他们是社会主义者，而其经验已将他们带到比英国与美国社会主义者更为靠后的几个阶段。诚然，德国社会主义者确曾从普鲁士传统中的某些方面在其国内获得不少支持；而普鲁士主义与社会主义之间的这种亲缘关系——在德国，这种亲缘关系曾为双方所同声颂扬——为我们的主旨更添一层佐证。5 但若因此而以为导致极权主义的是所谓“德国的特性”，而非社会主义成分，就大错特错了。德国与意大利、俄国的共同点，并非“普鲁士主义”，而是社会主义观念的流行；而国家社会主义的崛起，出自大众而非那些浸淫于、且受益于普鲁士传统的上层阶级。
