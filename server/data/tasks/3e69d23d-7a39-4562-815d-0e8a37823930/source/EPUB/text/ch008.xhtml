1976年版序言

本书写于1940至1943年间的业余时光，那时我的心思仍主要萦绕在纯粹经济理论的问题上。出乎意料的是，它却成了我在一个新领域里三十余年工作的起点。之所以在这一新方向上迈出第一步，缘于我对英国“进步”圈子中对纳粹运动性质的完全误读深感恼火。这份恼火促使我先写了一份致伦敦政治经济学院（LSE）时任院长威廉·贝弗里奇爵士的备忘录，继而写成1938年刊于《当代评论》（Contemporary Review）的一篇论文；应芝加哥大学哈里·G·吉迪恩斯教授之邀，我将其扩充，收入他主编的“公共政策小册子”中，1 而当我发现英国那些比我更能胜任的同事都忙于更迫切的战时事务、无暇顾及此题时，我终于（也可以说是出于勉强）把它扩展成这本“应时而作的小册子”。尽管本书出人意料地成功——尤其是最初并未考虑的美版，其成功甚至超过英版——我很长一段时间对它并不完全坦然。虽然我在书一开头已坦白声明这是一部政治著作，但多数社会科学同行让我觉得我把才力用在了“错误的一边”；而我自己也不无不安：超出技术经济学的范围，或许已逾越了我的胜任边界。关于本书在某些圈子里引起的盛怒，以及它在英国与在美国迥乎不同的反响，我不想在此赘述——二十年前我已在美版平装本的序言里谈过一些。仅为点明一种广泛反应的特征，我姑举一例：一位知名哲学家（此处不指名）写信责备另一位学者夸赞这本“丑闻之书”，而他“当然并未读过”！2

然而，尽管我竭力想回到本来意义上的经济学，我仍无法摆脱这样的感觉：我无心涉足的这些问题，比经济理论更具挑战、更为重要；而我在初稿中所言，亟需澄清与扩展。写作此书时，我还远未能充分摆脱主流舆论支配的诸多偏见与成见；更谈不上完全避免那些我后来深切自觉到的术语与概念上的混乱。另一方面，若缺少对“恰当运行的市场秩序所需何物、能成何功”的充分说明，本书对社会主义政策后果的讨论当然是不完整的。此后我在这一领域的工作，主要便致力于后者。旨在阐明自由秩序之本质的努力，首先结晶为《自由宪章》（1960）一书，我在其中基本尝试将19世纪古典自由主义的学说加以重述并使之更为自洽。意识到此种重述仍留下一些重要问题未答，我又进一步尝试在三卷本的《法律、立法与自由》中给出自己的答案，其首卷于1973年问世。3

过去二十年间，我自以为在本书所论问题上学到了不少——尽管我在此期间几乎未曾重读此书。如今为了写这篇序言而重读之后，我不再歉然，反倒第一次为它感到颇为自豪——也为那句“献给一切党派的社会主义者”的题献所包含的洞见而自豪。的确，虽然其间我学到了许多当初尚不知的东西，但我也常常惊讶地发现：许多后来得到证实的见解，我在这项努力之初便已预见；而尽管我后来的工作或许对专业读者更有裨益，如今我也可以毫不迟疑地向普通读者推荐这本早期著作——它提供了一种简明、非技术性的入门，以理解我看来仍是我们必须解决的最为不祥的问题之一。

读者或许要问：这是否意味着我仍愿意为本书的主要结论辩护？总体上答案是肯定的。我必须补充的最重要限定，是在此期间术语发生了变化，因而书中的表述可能被误解。我写作时，“社会主义”无歧义地指生产资料的国有化及其所使成为可能并所必需的中央经济计划。从这个意义上讲，譬如瑞典今日的社会主义化程度，远低于英国或奥地利，尽管人们通常把瑞典视为更“社会主义”。这乃由于“社会主义”现多指通过税收与福利国家制度进行的大规模收入再分配。就后一种社会主义而言，本书所讨论的那些效应的发生更为迟缓、间接且不完全。我相信最终的结果趋同，尽管带来结果的过程与本书所述并不完全一致。

人们常指称我主张：凡朝向社会主义迈进一步，必然走向极权。纵令此危险存在，本书并未如此断言。本书所含者，是一则警示：除非我们修正政策原则，否则必将招致一些极不愉快的后果——而这些后果，正是多数倡导该等政策的人所不愿见到的。

我如今自觉本书最不足之处，主要在于我对俄国共产主义经验的意义着墨太少——若想到我写作时俄国尚为战时盟友，这或可见谅——以及我尚未完全摆脱当时流行的干预主义迷信，因而做出了一些我现今认为并无根据的让步。而在某些方面，我当时显然也未充分意识到问题已糟到何等地步。譬如，当我设问：“如果希特勒是以严格的合宪方式取得不受限制的权力，谁还能说德国仍然维持着法治？”我本以为这只是个修辞疑问句；岂料后来却发现，汉斯·凯尔森与哈罗德·J·拉斯基两位教授，及很可能追随这两位有影响力作者的许多社会主义法学家与政治学家，竟恰恰持此主张。4 更一般地说，对当代思想与制度趋势的进一步研究，不但未能消释我的忧惧，反而有所加深。自我写作以来，社会主义思想的影响与人们对掌握极权之人“善意”的天真信赖，都显著增长。

长期以来，我不免郁郁：世人更以这本“应时小册子”知我，而非以我的严格科学研究相识。如今，在三十余年后重新检视当时所写，我已不复如此。尽管书中有不少内容在当时尚难以充分论证，但它是一次真诚的求真努力；我相信其中的洞见，即便对不同意我的人，也能有所裨益，帮助其避免严重的危险。

F. A. 哈耶克
