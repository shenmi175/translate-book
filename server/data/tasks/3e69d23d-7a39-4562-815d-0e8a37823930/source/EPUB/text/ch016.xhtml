经济控制与极权主义

对财富生产的控制，就是对人类生命本身的控制。
——伊莱尔·贝洛克（Hilaire Belloc）1
（通俗解释：谁掌握了“赚钱与生产”的开关，谁就能左右人们怎样活。）

大多数认真考虑过其任务之实际层面的计划者，对这样一点几乎没有怀疑：一个“被指挥的经济”必须或多或少以独裁方式运转。一个由无数相互关联的活动构成的复杂体系，倘若要被有意识地指挥，就必须由一支单一的专家班子来指挥；最终的责任与权力必须落在一位“总司令”的手里，而其行动不得受民主程序的羁绊——这实在是中央计划思想的显而易见之结论，足以赢得相当普遍的认同。计划者给我们的安慰是：这种威权式的指挥将“只”适用于经济事务。比如，颇具名望的经济计划倡导者斯图亚特·蔡斯就向我们保证：在一个计划社会里，“政治民主可以保留，只要它把自己局限在经济事务之外的一切方面。”2 这类保证通常伴以另一种暗示：只要我们在生活中那些应属“次要”的方面放弃自由，就能在追求更高价值的方面得到更大的自由。基于这种理由，许多厌恶政治独裁的人反而常常呼吁在经济领域来一位“独裁者”。

这些论证诉诸我们最好的本能，亦每每吸引最优秀的头脑。倘若“计划”真能使我们摆脱琐碎之忧，从而更易把生活过成“朴素而高远”的样式，谁会贬低这样的理想？倘若我们的经济活动真只关乎人生中较低微、甚至较污浊的一面，那么我们当然应当竭尽所能，寻求摆脱对物质目标的过度操劳，把它们交由某种功利机器照料，而让我们的心灵转向人生的更高境界。

不幸的是，人们由此而获得的“安心”——以为掌控经济生活的权力不过是对次要事务的权力，因此无须太在意对我们经济自由的威胁——完全没有根据。此种安心，很大程度上源自一个误解：以为存在“纯粹的经济目标”，它们与人生其他目标相互分离。除了守财奴这类病态个案之外，根本没有这种东西。理性存在者之活动的“最终目的”，严格说来从非“经济性的”。严格说来，根本没有“经济动机”，只有“经济因素”在制约着我们对其他目的的追求。日常语言中所谓“经济动机”，不过是对“通用机会”的渴望，是对“实现未特定之目的的能力”的渴望而已。3 我们之所以追逐金钱，只因它能为我们打开最宽广的选择范围，让我们更自由地享用努力之果。正因为在现代社会里，人们主要通过“收入的限制”来感受相对贫困对自己施加的限制，许多人便开始憎恶金钱，把它当成这种限制的象征——这恰是把“媒介”错当成了“原因”。更为真实的说法应当是：金钱乃人类发明的最伟大的自由工具之一。正是金钱，使得现存社会中的穷人也能拥有令人惊讶的选择幅度——这个幅度甚至超过了不太久远的过去里那些富人的可得范围。若我们设想：正如许多社会主义者一贯主张的那样，将所谓“金钱动机”大量改换为“非经济的激励”——比如不再以金钱奖励，而改以公开的褒赏或特权、对他人的权力、更好的住房或食物、旅行或受教育的机会——我们就更能理解金钱所提供之服务的意义。那样一来，受奖者便不再能自己选择，决定的不仅是“奖励的大小”，更是“以何种具体形式享受奖励”的人，将变成“制定奖惩的人”。

一旦我们意识到：并不存在一个“独立的经济动机”，而“经济得失”不过是“在我们仍能决定‘哪些需要或欲望’受影响的领域里的得失”，我们也就更容易看清一个普遍信念中的真实内核——即经济事务对我们只是较次要的——并理解人们为何常轻蔑所谓“不过是经济上的考虑”。在市场经济中——而且唯有在这种自由经济中——这种看法在某种意义上确属合理。只要我们能自由支配自己的收入与全部财物，经济损失在任何时候都只会剥夺我们那些我们自己视为“最低重要”的那一层欲望。所谓“不过是经济上的损失”，就是指：它的影响仍可由我们“转嫁到较不重要的需要上”；相反，当我们说某种损失“价值远大于其经济价值”，甚至“无法以经济术语估量”时，这意味着“我们必须承受其落点”。经济收益亦复如是。换言之，经济变动通常只影响我们需要的“边缘”“余幅”。有许多事物，比任何经济得失可能影响到的东西都更为重要；在我们心中，它们远高于“生活方便”，甚至高于许多会受经济波动影响的“生活必需”。与这些相比，“肮脏的铜臭”、我们“经济上好一点还是差一点”的问题，似乎并不重要。于是，许多人便以为：像经济计划这样只影响“经济利益”的东西，不可能严肃地干扰到人生中更基本的价值。

然而，这却是一个错误的结论。恰恰因为在经济事务上“由我们自己来决定何者更重、何者更轻”，经济价值才会在我们眼里显得低于许多其他东西。或者说，正因为在现存社会里，“我们要自己解决人生中的经济问题”。在我们的经济追求上受控，便意味着：除非我们声明自己“具体要干什么”，否则我们随时都在受控；而一旦我们声明了具体目的，就还必须“获得批准”——于是我们就实际上在一切方面受控。

因此，经济计划所提出的问题，不仅仅是：我们能否以自己喜欢的方式去满足“我们视为或多或少重要的需要”。问题在于：由我们自己决定何者为重、何者为轻，还是由“计划者”来决定。经济计划所影响的，将不仅仅是我们在轻蔑“不过是经济上的”时所想到的那些“边缘需要”。实际上，它意味着：我们作为个体将不再被允许自己决定“什么算边缘、什么不算边缘”。

指挥全部经济活动的权威，不仅要管我们生活中与“较低微之物”有关的那一部分；它要管的是“用于我们一切目标的稀少手段的配置”。而凡掌握全部经济活动者，即掌握“用于我们一切目标的手段”者，必将决定“哪些目标得到满足、哪些不得满足”。这才是问题的症结。经济控制并非对“可与人生其他部分割裂开来的某一片段”的控制；它是“对用于一切目标之手段”的控制。凡独掌其手段者，亦必决定“服务哪些目标、哪些价值更高哪些更低”——一句话，决定“人应当相信什么、追求什么”。中央计划所言“由共同体而非个人来解决经济问题”，其意在此；但这也意味着：必须由共同体，确切地说，由其代表，来决定不同需要的“相对重要性”。

计划者承诺的所谓“经济自由”，恰恰意味着：我们被解除“自行解决经济问题的必要”，由他人替我们做出那些常常格外痛苦的抉择。既然在现代条件下，我们几乎一切都要依赖“同胞所提供之手段”，经济计划便不可避免地会把我们几乎整个生活都纳入指挥之下。几乎没有哪一方面不在其“有意识的控制”之内：从最基本的需要，到我们与家人和朋友的关系；从工作的性质，到闲暇的使用。4

即便计划者不通过“直接控制消费”来行使权力，他对我们私人生活的支配也丝毫不会减弱。尽管一个计划社会或许会在某种程度上采用配给等手段，但计划者权力的根源不在此；即便名义上让消费者“自由支配”收入，也难以实质削弱其效力。这种对“一切消费”的权力，根源在于其对“生产”的控制。

在竞争社会里，我们之所以有选择自由，就在于：若一个人不愿意满足我们的愿望，我们还可以转向另一个人。但若我们面对的是“垄断者”，我们便任其摆布。指挥整个经济体系的权威，正是人所能设想的“最强大的垄断者”。虽然我们或许可不必担心这样的权威会像私人垄断者那样利用权力谋取最大财利、敲骨吸髓——它的目的大概并非“攫取最高金钱收益”——但它将拥有“完全的权力”来决定“我们得到什么、在何种条件下得到”。它不仅能决定“哪些商品与服务会供应、供应多少”，还能决定“按地区与群体如何分配”；它若有此意，也可对“具体个人”进行任意程度的差别对待。回想多数人提倡“计划”的初心，我们很难怀疑：这项权力将被用来“扶其所好之目标”，并且阻止“其所不许之追求”。

通过控制“生产与价格”所获得的权力，几近无边。在竞争社会里，我们为某物所付的价格——也即我们以某物换取另一物的比率——取决于：当我们取走一种东西时，我们使“社会其他成员”失去了多少“其他东西”。这个价格并非任何人“有意识的意志”所决定。若实现我们目标的一条路径对我们来说“代价太高”，我们仍可自由试行他途。横在我们面前的障碍，并非源于有人“不赞同我们的目标”，而是因为“同样的手段在别处也被需要”。而在一个“由权威看顾着我们所追求之目标”的指挥经济中，它必然会运用其权力来“资助某些目标”，并“阻止另一些目标”的实现。决定我们获得什么的，不再是“我们自己的好恶”，而是“他人的好恶”。且由于该权威有能力挫败任何“规避其指引”的努力，它对我们消费的控制，会几乎与“直接命令我们如何花钱”一样有效。

不止于“作为消费者”，甚至并非主要在“作为消费者”的角色里，我们的日常生活将被该权威“塑造并引导”。在“作为生产者”的角色里，更是如此。人生的这两个方面不可分割；对大多数人而言，工作时间占据人生极大一部分，而工作也往往决定着我们“在何处”“与哪些人”一起生活。因此，在“选择工作”上拥有一定自由，恐怕比在“闲暇中如何花钱”的自由对幸福更为重要。

诚然，即便在最理想的世界里，这种自由也十分有限。能在职业上“任择其志”的人，历来不多。重要的是：我们“多少有点选择”，我们不至于被绑死在“某个被替我们选定的岗位上”，或被过去自选的岗位永远束缚；只要“某个位置变得难以忍受”，或我们“一心向往别处”，通常总有出路：有能力的人可以付出某种牺牲来换取目标的实现。没有什么比“知道自己再怎么努力也改变不了现状”更叫人难以忍受了；即便我们也许永远拿不出那份“破釜沉舟的决心”，但只要“知道如果够努力就能逃离”，许多本来难以忍受的处境便会变得能够忍受。

这并不是说：在这一点上，我们当下的世界——或过去最自由的时代——已经尽善尽美，无须改进。恰恰相反，还有许多可做之事，可以扩大人们的选择机会。在这里，与其他方面一样，国家能做很多事情：传播知识与信息，协助人员流动，等等。但关键在于：真正能“增加机会”的那种国家行动，与如今普遍倡导并实行的“计划”，几乎完全相反。多数计划者固然承诺：在新的计划世界里，“自由选择职业”将被严格保留，甚至加以扩展。但他们许下的承诺，超出了他们的可能。如果他们要“计划”，就必须管控“进入各行各业的门槛”，或者“报酬条件”，抑或二者兼而控之。在几乎所有已知的计划实例中，“设立这类控制与限制”，都是最先采取的措施之一。如果这类控制被普遍施行，并集中于单一的计划权威之手，不难想见，所谓的“自由选择职业”将成何等面目。这种“选择自由”只会是虚饰的：在“事理本身要求区别对待”之处，“承诺不搞区别对待”，不过是自我欺骗；人们所能指望的，不过是“权威”据其自认的“客观标准”来做选择。

即便计划权威只限定于“确定雇佣条件”，并试图通过调节这些条件来调节人数，结果也不会好多少。只要它一刀切地“规定某一类的报酬”，它就能与“明文禁止某些人进入”一样有效地将一部分人排除在许多行业之外。一个容貌平平却渴望做售货员的女孩，一个体弱却心心念念某种“力有不逮之工种”的男孩，以及更一般意义上“看似资质较差或不大合适”的人，在竞争社会里并非必然被排斥；只要他（她）足够看重这个位置，往往可以“以经济上的牺牲换取一个起步机会”，而后再以起初不那么显眼的长处“迎头赶上”。但当“权威为整类岗位统一设定薪酬”，并以“客观测试”在候选者中作出甄别时，他们对这份工作的“渴望之强弱”，便几乎毫无用处。“资格不合标准类型的人”“性情不属常见类型的人”，将无法再与某个“恰能包容其特殊需要的雇主”达成特别安排；那些“宁愿要不规则的工时、甚至宁愿要一种随遇而安的小而或许不稳的收入”以换取自由的人，也不再有这种选择。条件将无一例外地变成“大组织里不可避免、而且更糟”的那种样式——因为“已无逃离之路”。我们不再能“在我们自认值得的地方与时刻，才选择理性或高效”；而是人人都得遵循“计划权威为简化其任务所必须设定的标准”。为了让这项庞大任务尚可操持，它不得不把人类能力与性情的多样性压缩为少数几个“易于互换的类别”，而刻意忽略那些细微的个别差异。

尽管计划宣称其宗旨是“让人不再只是手段”，但事实上——鉴于计划不可能把个体之好恶纳入考量——个体将比以往更像“纯粹的手段”，被当局用于诸如“社会福利”“共同体利益”之类抽象物的服务之中。

在竞争社会里，“绝大多数东西都可以买到”，尽管我们必须付出的代价常常残酷地高。这个事实的重要性，几乎怎么强调都不为过。它的替代者并不是“完全的选择自由”，而是“必须服从的命令与禁令”，以及最终对“有权者的恩典”的依赖。

种种混乱的征兆之一，是“在竞争社会里几乎一切都能以价格购得”，竟成了被指责的理由。若那些抗议“把更高的价值与钱挂钩”的人真正的意思是——“我们不应被允许为守住更高价值而牺牲较低需要，由他人替我们做这个选择”——那么这种诉求实在古怪，也很难说表现了对个人尊严的尊重。生命与健康、美与德、荣誉与心安，往往只能以相当大的物质代价来保护；在这之间必须有人作出选择，这如同我们有时并不愿为保护这些更高价值而付出必要的物质代价一样无可否认。

举一个例子：我们当然可以把汽车事故的伤亡降到零——只要我们愿意承担代价，哪怕仅仅是“取消一切汽车”。无数其他场景也一样：我们不断以自身与他人的生命健康，乃至精神世界的美好价值，去冒险，以换取我们同时又轻蔑地称作“物质舒适”的东西。事情不能不是如此，因为我们的一切目标，都在竞争同一批手段；若这些“至上之价值”绝不容许有任何风险，我们就无法追求除此之外的任何东西。

人们希望摆脱“冷酷事实迫使他们做出的痛苦抉择”，这并不奇怪。但很少有人愿意通过“让别人替他们做选择”来摆脱。人们只是希望“根本没有必须做选择的情形”。他们太容易相信：“选择其实并非必要，是现行经济制度强加给他们的”。他们真正怨恨的，是“经济问题”的存在本身。

人们对“经济问题已经不复存在”的一厢情愿，又被“不负责任的‘潜在丰裕’之谈”所巩固——若这是真的，的确意味着不存在“迫使人必须抉择的经济问题”。然而，自社会主义诞生以来，尽管这一诱饵换过许多名称，它仍然像百余年前第一次被拿出来时一样“显而易见地不真实”。在这整个期间，芸芸鼓吹者中竟无一人拿出过“可行方案”，能把“生产”提高到足以消除哪怕只是“西欧社会所认为的贫困”的程度——更不必说“整个世界”了。凡谈论“潜在丰裕”者，要么不诚实，要么不知道自己在说什么，读者大可以据此断定。5 然而，正是这种虚假希望，跟其他任何因素一样，把我们推向“计划之路”。

当大众运动仍在从这种虚假信念中获利之时，认真研究问题的学者中，关于“计划经济将比竞争体系产生更大产出”的主张，却正日益式微。甚至相当多持社会主义观点、但认真研究过中央计划难题的经济学家，如今也不过寄望于：“计划社会能与竞争体系的效率相当”；他们支持“计划”，不再因为“它更高的生产力”，而是因为“它能使我们实现更公正与更平等的财富分配”。这的确是唯一还可认真讨论的“计划理由”。无可争辩的是：若我们要实现“合乎某一预先设定标准”的分配，若我们要有意识地决定“谁该拥有什么”，我们就必须“计划整个经济体系”。但问题仍在于：为实现某人心目中的“正义理想”而付出的代价，是否必将是比“被大量诟病的自由经济力量的自发作用”所造成者更甚的“不满与压迫”。

如果我们指望通过这样一种想法来安慰自己，就会严重自欺：采用中央计划，无非是“短暂的自由经济”之后“回到大部分时代约束经济活动的那些纽带与规制”，因此对“个人自由”的侵犯不会比“自由放任”之前更甚。——这是危险的幻象。即便在欧洲历史上“对经济生活的编制”走得最远的时期，也不过是“创设一套一般性的、半永久的规则框架”，在此之内，个人依旧保有宽广的自由领域。当时可供运用的控制装置，并不足以实施“超过一般指示”的更具体支配。即使控制最为周密，它也不过延伸至“个人参与社会分工”的那些活动而已；在其远为广阔的“自给自足”领域，个人依旧可以随意而为。

今日的情势则全然不同。在自由时代，分工的推进造就了这样的状况：我们几乎每一项活动都是“社会过程”的一部分。这种发展不可逆转；正由于它，我们才能以接近现今的标准来供养如今庞大的人口。其结果是：用中央计划取代竞争，将需要对我们生活中远比以往任何时代都更大的部分实施中央指挥。它不可能止步于我们所理解的“经济活动”，因为如今我们几乎在生活的每一个环节都要依赖“他人的经济活动”。6 我们的社会主义者以“集体满足需要”的热情，为极权主义铺好了道路；这种热情既希望我们把“享乐”与“必需”都按规定时间、以规定形式来接受，当然也多少带着政治教育的用心。但其根源，同样在于“计划”的必然要求：它在于“剥夺选择”，以便“把最合乎计划的东西”在“由计划决定的时点”给我们。

人们常说：没有经济自由，政治自由便毫无意义。这句话固然不错，但其真正含义，几乎与计划者所用的意思相反。作为一切其他自由之前提的“经济自由”，绝不能是社会主义者许诺的那种“免于经济忧患的自由”——那只能通过同时剥夺个人的“选择之必要”与“选择之能力”来获得；它必须是“我们在经济活动中的自由”，而这种自由与“选择权”相伴，必然也带来“这种选择之风险与责任”。
