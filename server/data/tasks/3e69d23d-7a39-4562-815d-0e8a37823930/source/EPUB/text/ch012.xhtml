个人主义与集体主义

社会主义者同时相信两样东西，而这两样东西截然不同，甚至可能相互矛盾：自由与组织。——埃利·阿莱维1
（通俗解释：社会主义既想要“自由”，又要高度“组织化”，这两者常常彼此冲突。）

在我们推进核心问题之前，还有一道障碍需要跨越。一种混乱在很大程度上要为我们正漂向无人真正想要的境地负责，必须先予以澄清。这种混乱不在别处，正是关于“社会主义”概念本身。它可能仅仅意味着——而且人们常用它来描述——社会正义、更大的平等与安全这些社会主义的终极目标。但它同时也指称大多数社会主义者希望用以达成这些目标的特定方法；而许多行家甚至认为，只有靠这些方法，才能彻底而迅速地实现目标。在这种意义上，社会主义意味着废除私营企业与生产资料的私人所有，建立一种“计划经济”体制，其中以利润为目的的企业家被一个中央计划机构所取代。

有许多人自称社会主义者，却只关心前者——他们热忱地信奉社会主义的那些终极目标，却既不关心也不理解这些目标如何达成；他们只是笃信不论代价为何，这些目标都必须实现。可是，对几乎所有把社会主义不只是当作一种希望、而是当作现实政治目标的人来说，现代社会主义的那些典型方法与其目标本身同样不可或缺。另一方面，也有许多人对社会主义的终极目标的珍视丝毫不亚于社会主义者，但他们因为看见社会主义者所提出的方法会危及其他价值而拒绝支持社会主义。于是，关于社会主义的争论在很大程度上就变成了关于手段而非目的的争论——尽管“社会主义的不同目标能否同时实现”这一问题也牵涉其中。

这本已足以造成混乱；而“否认那些反对手段的人也同样看重这些目标”的常见做法，更让混乱雪上加霜。但这还不是全部。情况还因另一事实而更趋复杂：同一种手段——即作为社会主义改革主要工具的“经济计划”——也可以被用来追求许多别的目的。若要使收入分配符合当下对社会正义的观念，我们就必须对经济活动作中央指挥。因此，凡是要求以“为使用而生产”取代“为利润而生产”的人，都希望“计划”。但如果我们要以某种在我们看来恰与正义相反的方式去调节收入分配，这种计划同样不可或缺。无论我们是不是希望把人世间更多的好处分给某个种族精英、北欧人、或某个政党或贵族的成员，我们所不得不采用的方法，恰恰与那些可以保障平均分配的方法相同。

或许，用“社会主义”来指称其方法而非目标，似乎并不公平——用一个在许多人心中代表终极理想的词去标示某种具体方法。因而，更可取的做法，大概是把可以用于多种目的的方法称为“集体主义”，而把社会主义视为这一属类中的一种。可是，尽管在多数社会主义者看来，只有集体主义的某一“种”才是“真正的社会主义”，我们必须始终记得：社会主义是集体主义的一种；因而，凡对“集体主义一般”成立的命题，对社会主义也同样成立。几乎所有社会主义者与自由主义者之间的争点，都关乎“集体主义各种形态所共有的方法”，而非社会主义者欲以之实现的那些特定目标；而本书将要讨论的一切后果，亦无不源自集体主义的方法，而与其所服务的目标无关。还不可忘记，社会主义不仅是迄今最重要的一种集体主义或“计划”形式，而且正是社会主义说服了有自由心志的人们，再度接受他们曾经推翻过的经济生活编制——用亚当·斯密的话说，这种编制让政府“为求自存，不得不变得压迫而专横”。2

即便我们同意用“集体主义”来涵盖一切类型的“计划经济”（不论计划的目的为何），常见政治术语所致的含混仍未终结。若我们申明此处所说的，是那种为实现某种既定的分配理想而不可或缺的计划，这一术语的意义会稍为明确。然而，正因为“中央经济计划”的吸引力很大程度上源自其意义的暧昧，我们在讨论其后果之前，务须先就其确切含义达成一致。

“计划”之所以受欢迎，很大程度上因为人人当然希望我们能尽可能理性地处理共同问题，并在此过程中尽可能运用预见。从这个意义上讲，凡非绝对宿命论者都是计划者；每一个政治行动都是（或理应是）一种计划；差别只在好与坏、英明远见与愚昧短视之间。一个经济学家——其全部任务在于研究人们实际上如何计划、以及他们可能如何计划其事务——是最不可能反对这种一般意义上的“计划”的人。然而，当今那些热情倡导计划社会的人所使用的“计划”，并非此意；我们要使收入或财富的分配符合某一特定标准时所必需的那种计划，也不止于此。按现代计划者的看法，并为了他们的目的，仅仅设计一个“最理性、持久的框架”，让各人可按其个人计划开展各自活动，这是远远不够的。依他们看来，这种自由主义的方案根本算不上“计划”——它确实不是一个为满足“谁应得什么”这类特定看法而设计的计划。我们的计划者所要求的是：依据一纸单一的计划，对一切经济活动实行中央指挥，明确规定社会资源应如何被“自觉地引导”，以确定方式服务于特定目标。

因此，现代计划者与其反对者之间的争论，并不是关于我们是否应在社会可能的各种组织形态之间作出理性选择；也不是关于我们是否应在规划公共事务时运用前瞻与系统思维的问题；而是关于“如何做才最好”。问题在于：为达此目的，是更好地让掌握强制力的人总体上仅限于创造某种条件，使个人的知识与主动性得以最大施展，从而让他们各自的计划更可能成功；还是说，为了理性地利用我们的资源，必须依某种自觉构拟的“蓝图”，对一切活动实行中央指挥与统筹？各党派的社会主义者已将“计划”一词据为己有，用以特指后者，如今此义也大体被普遍接受。然而，尽管此用法意在暗示：这才是处理我们事务的唯一理性方式，但这当然并不能证明其为真。恰恰在此处，计划者与自由主义者存在分歧。

切勿把对这种“计划”的反对，混同于对“自由放任”的教条式拥护。自由主义的论证主张：把“竞争的力量”作为协调人类努力的一种手段，尽可能加以善用；这并非主张“任其自流”。这种论证的根据在于：凡能建立起有效竞争之处，竞争比任何其他方式都更善于引导个人努力。它并不否认，甚至强调：要使竞争带来良效，必须有深思熟虑的法律框架；而现行或以往的法律规则都绝非没有严重缺陷。它也不否认：凡无法创造使竞争有效的条件之处，我们必须诉诸其他引导经济活动的方法。然而，经济自由主义反对用较劣的方法来替代竞争以协调个人努力。自由主义之所以看重竞争，不仅因为竞争在多数情况下是我们所知最有效的方法，更因为竞争是唯一能在不诉诸权威的强制或任意干预的条件下，使我们的活动彼此调适的方法。事实上，支持竞争的主要论据之一，正在于它使“有意识的社会控制”成为不必要，并给予个人机会来判断：某种特定职业的前景，是否足以弥补与之相伴的不利与风险。

把竞争作为社会组织原则而成功运用，意味着排除某些类型的对经济生活的强制性干预，但也容许另外一些干预，有时这些干预甚至会大大助益竞争的运行，并且竞争还需要某些政府行为的支持。不过，对“哪些地方应当严禁强制”这些负面条件之所以受到格外强调，自有其道理。首先，市场中的当事人必须可以自由地以任意价格买卖——只要他们能找到交易相对方；而任何人都应当可以自由地生产、出售并购买任何可以被生产或出售的东西。同样重要的是，进入各行各业必须在平等条件下向所有人开放；法律不应容忍个人或团体用公开或隐蔽的强力限制这种进入。凡试图控制某些特定商品的价格或数量的做法，都会剥夺竞争促成个人努力有效协调的能力，因为此时价格变动不再记录一切相关境况的变化，也不再为个人行动提供可靠的指引。

然而，对“仅仅限制允许使用的生产方法”的措施，情况并非必然如此——只要这些限制对一切潜在生产者一体适用，且不被当作间接控制价格与数量的手段。此类对生产方法的管制虽都会增加成本（即为产出同量产品而必须投入更多资源），但可能完全值得。禁止使用某些有毒物质或要求在使用时采取特殊防护，限制工时，或要求一定的卫生条件，与维护竞争完全相容。这里唯一的问题是：在具体个案中，所得的好处是否大于其所加之社会成本。同样，只要其组织方式不致使竞争在广阔领域内失效，维护竞争也并不与一套广泛的社会服务体系相抵触。

遗憾但并不难以解释的是，相较于上述“禁止之处”，人们过去对“竞争成功运作所需的正向条件”关注得少得多。竞争的运转不仅要求恰当组织若干制度，如货币、市场与信息渠道——其中一些永远无法由私人企业充分提供；更重要的在于，一个适当的法律制度之存在——此法律制度既要维护竞争，又要使其尽可能带来良效。法律仅仅承认“私人产权”与“契约自由”的原则，远远不够；许多事情取决于“产权”之在不同对象上的精确定义。对那些能使竞争体系高效运行的法律制度形态的系统研究，长期以来严重缺位；有充分理由认为，这里的一些严重缺陷，特别是在公司法与专利法方面，不仅使竞争的效能大打折扣，甚至还在许多领域导致竞争本身的毁灭。

最后，确有一些领域，任何法律安排都无法创造出竞争与私有制得以发挥效用的主要条件：即“财产所有者因其财产提供的一切有用服务而受益，并因其使用所造成的一切损害而受罚”。例如，当无法使某些服务的享受以支付价格为条件时，竞争将不会产生这些服务；同理，当财产的某些使用对他人造成的损害无法有效地归责于该财产的所有者时，价格机制也会同样失灵。在所有这些情况下，私人计算中纳入的项目与影响社会福利的项目发生背离；每当这种背离变得重要，我们就可能需要在这些服务的供给上寻求竞争以外的方法。于是，无论是在道路上设立指示牌，还是（在多数情形下）修建道路，都无法向每一位使用者分别收费。再如，毁林、某些耕作方式、或工厂的烟尘与噪音所带来的某些危害，既无法局限于相关财产的所有者，也无法局限于那些愿意在取得约定补偿的条件下承受损害的人。在这些场合，我们必须找到价格机制调节的替代物。但事实是：当无法创造竞争正常运作所需条件时，我们不得不诉诸权威的直接规制；这并不能证明，在可以让竞争发挥作用的地方，我们也应当把竞争废止。

创造使竞争尽可能有效的条件；在竞争无法有效之处对其加以补充；提供那些用亚当·斯密的话来说“对一个大社会或许至为有利，却因其性质使利润永远不可能补偿任何个人或少数人的开支”的服务——这些任务的确为国家活动提供了广阔且不容置疑的领域。3 在任何可以理性辩护的制度中，国家都不会什么也不做。一个有效的竞争体系，与任何其他体系一样，需要一个“经明智设计并不断调适的法律框架”。甚至其正常运作最为根本的前提——防止欺诈与欺骗（包括利用无知）——也为立法活动提供了一个重要而尚未完全达成的目标。

然而，当各国才刚开始不久地着手于为竞争的良性运行创建合适框架之时，国家却纷纷转而采取一种不同、且与之不可调和的原则去取代竞争。问题不再是让竞争发挥作用并对其加以补充，而是要把竞争完全排挤出去。务须把话说清楚：现代的计划运动，乃是一场“反竞争”的运动——在它的新旗号之下，所有竞争的老对手都汇聚了起来。如今，虽有各色利益集团试图借这面旗帜恢复自由时代所扫除的特权，但正是社会主义为计划所作的鼓吹，让自由心志的人们重新把“反对竞争”视为体面之举，并有效麻痹了人们对任何“扼杀竞争”的企图曾经应有的警惕。4 实质上，将左翼与右翼社会主义者联结起来的，正是这种“共同的反竞争敌意”与他们“以指令性经济取而代之”的共同愿望。尽管“资本主义”与“社会主义”这两个术语仍被普遍用来描述社会的过去与未来形态，但它们更多是遮蔽而非阐明我们正经历的过渡之性质。

然而，尽管我们所观察到的一切变迁都倾向于对经济活动实施全面的中央指挥，这场“全民反竞争”的斗争，首要地产生的，极可能是某种在许多方面更糟的局面——一种既不能令计划者满意，也不能令自由主义者满意的状态：即一种类似于工团主义或“社团主义”的产业组织形态，在其中竞争或多或少被压制，但“计划”却被交给各个行业的独立垄断体来掌握。这是在全社会“反对竞争而对其他问题鲜有共识”的情况下不可避免的第一步。通过在一个又一个行业中摧毁竞争，这种政策使消费者任由组织程度最高的行业里资本家与工人结成的联合垄断行动摆布。尽管这种状态在广大领域已经存在了一段时间，且许多混乱的（而更多是出于私利的）计划鼓动正是以此为目标，但这既不是一种可能持久的状态，也无法得到理性辩护。事实上，这种由产业垄断者各自为政的“独立计划”，会产生与计划论证所追求目标相反的效果。一旦到达此阶段，除了回到竞争之外，唯一的选择便是由国家来控制这些垄断——而若要使这种控制有效，就必须日益全面、日益细密。我们正在迅速逼近的，正是这一阶段。战前不久，有一份周刊指出：至少在英国领导层中，越来越多的迹象显示他们已习惯于以“受控垄断引领国家发展”的思路来思考——这大概真实反映了当时的情形。5 自那以后，战争极大加速了这一进程；而其严重的缺陷与危险，必将随着时间推移而愈益显露。

把经济活动的指挥完全集中于一处的想法，仍让大多数人感到惊惧——不仅因为任务之艰巨惊人，更因为“一切由单一中心指挥”的念头所带来的恐怖。然而，我们若仍在迅速走向这种状态，其主要原因之一，乃是多数人仍相信：在“个体化的”竞争与中央指挥之间，必定存在一条中道。的确，没有什么比以下观点更似乎合乎情理、更容易赢得理性人的好感：我们的目标既非自由竞争的极端分散，也非单一计划的完全集中，而应是二者某种明智的混合。然而，在此领域里，“常识”却是靠不住的向导。竞争固然能承受一定程度的规制，但它无法与计划任意程度地结合而不丧失其作为有效生产指引的性质；“计划”也并非一种“药物”，少量服用便能产生其彻底应用所期望的效应。竞争与中央指挥若不完整，二者都会变得拙劣低效；它们是用以解决同一问题的两个替代性原则，而二者混杂意味着没有一个真正有效，结果反倒比一以贯之地依赖其中任一制度更糟。换句话说，计划与竞争的结合，只有在“为竞争而计划”（planning for competition）时才可能，而非“以计划对抗竞争”（planning against competition）。

对本书的论证而言，至关重要的一点是：读者务必牢记，我们所批评的一切计划，专指“对抗竞争的计划”——即用来取代竞争的计划。此点更显重要，因为在本书的篇幅内，我们无法展开那种“为了使竞争尽可能有效而必需的计划”的讨论。只是由于当下“计划”一词的通用法几乎等同于前一种意义，为了简洁，我们有时难免仍简称其为“计划”——即使这等于把一个本该有更好归宿的好词拱手让给了我们的论敌。

4. 近来，确有一些学院派社会主义者在批评驱动与“对中央计划社会中自由被消灭的恐惧”推动下，设计出一种新的“竞争性社会主义”，希望由此规避中央计划的难题与危险，并把“废除私有制”与“充分享有个人自由”结合起来。关于这种新社会主义的讨论虽已在学术期刊上有所展开，但它几乎不可能为现实政治家所青睐。即便真有其事，也不难证明（正如作者在他处所尝试的——见《经济学季刊》（Economica）1940年）这些方案建立在错觉之上，并受制于内在矛盾。若要控制全部生产资源，就不可能不同时决定这些资源“用于谁、由谁用”。在这种所谓“竞争性社会主义”下，即便中央权威的计划采取更为迂回的形式，其效果也不会有根本不同；所谓“竞争”不过是幌子。［哈耶克此处所指为其论文《社会主义计算：竞争性的“解决方案”》，同前注。文中评述并批评了 H.
