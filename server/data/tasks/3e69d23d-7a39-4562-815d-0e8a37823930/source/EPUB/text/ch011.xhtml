伟大的乌托邦

之所以国家总是被人类变成“人间地狱”，恰恰是因为人类试图把它变成“天堂”。——荷尔德林1

社会主义取代自由主义，成为大多数进步人士所信奉的学说，这并不仅仅意味着人们忘记了过去伟大的自由主义思想家们关于集体主义后果的警告。这一切之所以发生，是因为他们被说服去相信与这些思想家所预言的完全相反的东西。令人惊讶的是，同一种社会主义，既早早被认定为对自由的最大威胁，而且一开始就公开地以反对法国大革命的自由主义为出发点，却最终打着自由的旗号赢得了普遍的接受。如今很少有人记得，社会主义在其起源时是赤裸裸的威权主义。奠定现代社会主义基础的法国作家们毫不怀疑，他们的思想只能通过一个强有力的独裁政府来实现。对他们而言，社会主义意味着通过在等级制度的基础上有意地重组社会，并强加一种带有强制性的“精神权威”，来“终结革命”的尝试。在自由问题上，社会主义的奠基者们毫不掩饰他们的意图。他们认为思想自由是十九世纪社会的根本之恶，而第一位现代的计划者圣西门甚至预言，那些不服从他所提议的计划委员会的人将会被“像牲畜一样对待”。2

直到1848年革命前夕强大的民主潮流兴起之后，社会主义才开始与自由的力量结盟。但新的“民主社会主义”花了很长时间才逐渐消除其前身所引起的怀疑。没有人比托克维尔更清楚：民主作为一种本质上的个人主义制度，与社会主义之间存在不可调和的冲突：

“民主扩展了个人自由的领域，”他在1848年说；“社会主义则限制了自由。民主赋予每个人尽可能高的价值；社会主义却把每个人变成一个单纯的工具、一个单纯的数字。民主和社会主义除了一个词——平等——之外毫无共同之处。但请注意其中的区别：民主在自由中追求平等，而社会主义则在约束与奴役中追求平等。”3

为了消除这种怀疑，并套上最强大的政治动力——对自由的渴望——社会主义越来越多地诉诸于一种“新自由”的承诺。社会主义的到来据说将是从必然王国跃入自由王国的一大飞跃。它将带来“经济自由”，而没有经济自由，已经获得的政治自由就“毫无价值”。只有社会主义才能完成这场为自由而进行的千古斗争，而获得政治自由只是第一步。

为了让这种论证听起来合乎情理，“自由”一词的含义被巧妙地改造了，这一转变至关重要。对于伟大的政治自由的使徒来说，“自由”意味着免于强制，免于他人专断的权力，意味着摆脱那些迫使个人只能服从某个上级命令的枷锁。然而，新的自由却被许诺为免于必然，摆脱那些不可避免地限制所有人（虽然对某些人远比其他人更为严酷）的处境的束缚。在人真正自由之前，必须打破“物质匮乏的专制”，放松“经济制度的限制”。

这种意义上的自由，当然只是权力4或财富的另一种说法。然而，尽管这种新自由的许诺常常伴随着对社会主义社会中物质财富大幅增长的不负责任的承诺，但人们对所谓“经济自由”的期望，并不是源于对自然吝啬本性的绝对征服。其真实的含义是：现存的不同人之间在选择范围上的巨大差距将会消失。因此，对新自由的要求实际上不过是对财富平等分配的旧要求换了一个名字。但这个新名字为社会主义者提供了另一个与自由主义者共有的词汇，而他们充分利用了这一点。尽管两个群体对这个词的理解不同，但很少有人注意到，更少有人会追问，这两种自由是否真的能够兼容。

毫无疑问，更大自由的许诺已经成为社会主义宣传中最有效的武器之一，而相信社会主义会带来自由的信念也确实是真诚的。然而，如果事实证明，那条被许诺为通向自由之路的道路，其实恰恰是通往奴役的康庄大道，那么这场悲剧只会更加深重。毫无疑问，正是这种更多自由的承诺，吸引着越来越多的自由主义者踏上了通往社会主义的道路，使他们对社会主义与自由主义之间的根本冲突视而不见，并常常让社会主义者得以篡用自由党的名义。作为自由主义传统的表面继承者，社会主义被大部分知识分子所拥抱；因此，他们觉得社会主义可能导致与自由相反的结果，自然是不可思议的。

然而，近些年来，关于社会主义不可预见后果的旧有担忧，却一次又一次从最出乎意料的地方被强烈表达出来。一个又一个观察者，尽管原本带着相反的预期来研究，却仍被“法西斯主义”和“共产主义”在许多方面的惊人相似所震撼。当英国及其他地方的“进步人士”还在自欺欺人地认为共产主义与法西斯主义代表着相对的两极时，越来越多的人开始自问：这些新的暴政是否其实是同一种趋势的产物。即便是共产主义者，也必然被一些证言所动摇，例如列宁的老友马克斯·伊斯特曼不得不承认：“斯大林主义非但不比法西斯主义更好，反而比法西斯主义更糟——更无情、更野蛮、更不公正、更不道德、更不民主，完全没有任何希望或顾忌来挽救”，甚至“更适合被称为超级法西斯主义”；而当同一位作者又承认“斯大林主义就是社会主义，它是国有化与集体化所不可避免、虽然未曾预料的政治伴随物，而他曾依赖这些作为建立无阶级社会计划的一部分”5，他的结论无疑具有更广泛的意义。

伊斯特曼的案例或许最为显著，但绝非第一个、也不是唯一一位对俄国实验抱有同情的观察者得出类似结论。数年前，美国记者W. H. 钱伯林在俄国生活十二年，亲眼见到自己所有的理想破灭，他在总结自己在俄国、德国和意大利的研究时指出：“社会主义至少在初期必然会被证明不是通向自由之路，而是通向独裁与反独裁、最激烈的内战。通过民主手段实现并维持的社会主义显然只属于乌托邦的世界。”6 同样，英国作家F. A. 沃伊特，在欧洲作为外派记者多年密切观察发展后得出结论：“马克思主义导致了法西斯主义和国家社会主义，因为从本质上看，它就是法西斯主义和国家社会主义。”7 而沃尔特·李普曼则深信：“我们这一代人正在通过经验学习，当人们从自由退回到一种强制性的事务组织时会发生什么。虽然他们向自己许诺更加丰富的生活，但在实践中却必须放弃；随着有组织的指挥加强，目标的多样性必然让位于统一。这就是计划社会与人类事务中权威原则的报应。”8

在近年来的出版物中，还可以从许多有资格判断的人那里找到类似的陈述，尤其是那些作为现已极权国家的公民，亲身经历了这种转变，并被迫因经验修正许多珍视信仰的人。我们再引用一位德国作家的话，他的结论或许比前面引述的更为公允：

“对通过马克思主义实现自由和平等的信仰彻底崩溃，”彼得·德鲁克写道，“迫使俄国走上与德国相同的道路，走向一种极权的、纯粹否定的、非经济的、不自由与不平等的社会。并不是说共产主义与法西斯主义本质相同。法西斯主义是共产主义被证明为幻觉之后所达到的阶段，而这种幻觉在斯大林主义的俄国和希特勒前的德国都同样被证明过。”9

纳粹和法西斯领导人的思想史同样意义重大。每一个观察过这些运动在意大利10或德国成长的人，都注意到许多主要人物，从墨索里尼起（包括拉伐尔和奎斯林在内），最初都是社会主义者，最后却成了法西斯或纳粹分子。11 对于普通成员，这一点更为真实。一个年轻的共产党员相对容易转变为纳粹分子，反之亦然，这在德国是众所周知的，尤其被两党宣传员所熟知。20世纪30年代，不止一位大学教师看到英国和美国学生从欧洲归来时，对自己到底是共产党员还是纳粹分子犹疑不决，唯一确定的是他们憎恨西方自由文明。

当然，在1933年之前的德国、1922年之前的意大利，共产党员与纳粹或法西斯分子之间的冲突，比与其他政党更为频繁。他们争夺的是同一种心态的支持者，并以异端的仇恨对待彼此。但他们的实践显示了二者的紧密联系。对双方而言，真正的敌人——那个他们毫无共同点、无法说服的人——正是传统意义上的自由主义者。对纳粹而言，共产主义者；对共产主义者而言，纳粹；对二者而言，社会主义者，都是潜在的新兵，都是合适的材料，只不过听信了错误的先知。而他们都清楚：与真正相信个人自由的人之间，不可能存在任何妥协。

为了不让人因任何一方的官方宣传而怀疑这一点，我再引用一段来自一位不应被怀疑的权威的陈述。在一篇题为《自由主义的重新发现》的文章中，德国宗教社会主义领袖之一爱德华·海曼教授写道：“希特勒主义自称既是真正的民主，又是真正的社会主义，而可怕的事实是，这种说法中确实包含一丝真实——极其微小，但至少足以成为这种荒谬歪曲的基础。希特勒主义甚至自称是基督教的保护者，而可怕的事实是，即便这种严重的曲解也能产生某种影响。但在这片迷雾中，有一个事实无比清晰：希特勒从未声称自己代表真正的自由主义。因此，自由主义便成为希特勒最憎恨的学说。”12 需要补充的是，这种仇恨之所以很少在实践中表现出来，仅仅是因为当希特勒掌权时，自由主义在德国事实上已名存实亡。而杀死它的，正是社会主义。

尽管许多近距离观察过从社会主义向法西斯主义转变的人已经越来越清楚地看到了两者之间的联系，但在民主国家中，大多数人仍相信社会主义与自由可以结合。毫无疑问，这里的大多数社会主义者依然深信自由主义的理想，一旦他们确信自己的纲领会导致自由的毁灭，他们一定会退缩。问题在于，这一问题至今仍未被真正认识，彼此最不相容的理想仍轻易地共存，以至于我们今天仍能听到诸如“个人主义社会主义”这样的自相矛盾的说法被认真讨论。如果正是这种心态让我们漂泊进入一个新世界，那么最迫切的任务莫过于认真审视这种在别处已经发生的演变的真正意义。虽然我们的结论只是印证了他人早已表达的忧虑，但如果不全面考察这种社会生活转型的主要方面，就无法看清为什么这种发展绝不能被视为偶然。民主社会主义，过去几代人的伟大乌托邦，不仅不可实现，而且追求它的过程会产生一种完全不同的结果，以至于如今渴望它的人，极少有人会愿意接受其后果。除非把这种联系在各个方面都揭示出来，否则许多人将依旧不愿相信。
