被遗弃的道路

一个纲领的基本论点并不是：这一代以逐利为目的的自由企业制度已经失败，而是：这种制度至今尚未真正得到尝试。
——F. D. 罗斯福1

当文明的进程突然拐了个意料之外的弯——当我们原本以为会持续推进的进步不见了踪影，反而眼前浮现出我们通常与蛮荒时代相联系的诸般祸患——我们自然会把责任推给除了自己以外的一切。难道我们不是都在尽己所能？难道不是我们许多最杰出的头脑在不懈努力，想把这个世界变得更好？难道我们的全部努力与期望，不都是奔着更多的自由、公正与繁荣去的吗？如果结果与我们的目标如此南辕北辙——如果自由与富足没有到来，束缚与贫困却近在眼前——那显然是某种阴险的力量挫败了我们的用心；我们成了某个邪恶权力的牺牲品，必须先战胜它，才能继续踏上通往更好未来的道路。无论我们在指认罪魁祸首时如何各执一词——或说是邪恶的资本家，或说是某个民族的恶劣精神，或说是长辈的愚蠢，或说是一个我们与之搏斗了半个世纪却仍未彻底推翻的社会制度——我们都（至少直到最近还）有一个笃定的信念：在上一代之间逐渐为大多数善意之人所共享、并决定了我们社会生活重大变迁的那些主导性观念，不可能错。我们几乎愿意接受关于当下文明危机的任何解释，除了一个：当今世界的处境也许真是我们自己的错误所致；我们追求的一些最珍视的理想，居然显现出与我们所期望的截然不同的结果。

当我们倾尽全力要把这场战争打赢时，人们有时很难记起：早在战争之前，我们如今为之而战的那些价值就在我们这儿受到威胁，并在别处遭到摧毁。虽然眼下这些彼此敌对的国家为了生存在战场上对垒，但我们不可忘记：这场冲突发端于一个不久之前还共同构成“欧洲文明”的世界内部的思想之争；而那些最终以极权体制告终的趋向，并非只存在于已为之沉沦的国家。如今首要的任务固然是赢得战争；可即便赢了，也不过是为我们赢得了再一次直面根本问题的机会，以寻求避免与我们相近的文明所遭厄运的道路。

现在，要把德国和意大利，或者俄罗斯，看作不是完全不同的世界，而是我们共同参与的一种思想发展之产物，这多少有些困难；至少就我们的敌人而言，把他们想成与我们截然不同并且他们那里发生的一切绝不可能在这里发生，要容易也更让人心安。然而，这些国家在极权制度兴起之前的历史，并无多少我们不熟悉的特征。眼下的外部冲突，正是欧洲思想转变的结果：别的国家在这条路上走得更快，以至与我们的理想发生了不可调和的冲突，但这场转变也从未不在我们身上留下痕迹。

或许恰因盎格鲁—撒克逊诸国在这场发展中（幸运地）落后于多数欧洲民族，它们尤其难以看清：世界变成如今这样，是思想变迁与人类意志的力量所致——人们并未预见到其结果；并非客观事实的自发变化迫使我们那样调整思维。我们依然把引导我们、并在过去一代中引导我们的那些理想，当作只能在未来实现的理想；也未意识到，在过去二十五年里，它们不仅改变了世界，也改变了我们自己的国家。我们仍以为，直到不久之前，我们一直受那些含糊其辞的“十九世纪观念”或“自由放任”（laissez-faire）原则所统治。与某些国家相较，从那些急于加速变革者的视角看，这种看法或许不无道理。但即便到1931年之前，英美两国沿着别人带头走上的道路还算是慢的，到那时它们也已走得如此之远，以至除非有人记忆能追溯到上一次大战前的岁月，他才会真正知道一个自由主义的世界是什么样子。2

然而，我们的国民仍鲜少意识到的关键，不仅在于上一代发生的变迁幅度之大，更在于这些变迁意味着我们的思想与社会秩序的演化方向发生了彻底逆转。早在极权主义幽灵成为现实威胁的至少二十五年之前，我们就已在一步步远离奠定西方文明之基的那些根本观念。我们带着极高的期望与雄心踏上的这条路，如今却把我们带到了极权恐怖的门前——这对仍拒绝把两者联系起来的这一代人而言，是个极为深刻的震撼。然而，这一发展不过印证了我们仍自称所信奉的自由主义先贤的告诫。我们一步步抛弃了经济事务中的自由——而没有这种自由，个人与政治自由在过去从未存在过。尽管十九世纪一些最伟大的政治思想家——托克维尔与阿克顿勋爵——曾经告诫我们“社会主义意味着奴役”，我们却始终朝社会主义的方向走去。3而如今，当一种新形式的奴役在我们眼前出现时，我们竟把这番告诫忘得一干二净，几乎不曾想到两者之间或许有关联。4

若把现代通往社会主义的潮流，放在更长的历史视野中，而不只是十九世纪的背景下，我们就会更清晰地看到：这不只是与近代的决裂，更是与西方文明整个演进的背离。我们正在迅速抛弃的，并不仅仅是科布登与布赖特、亚当·斯密与休谟，甚至也不仅是洛克与弥尔顿5的见解，而是西方文明自基督教与古希腊、古罗马奠基以来孕育出的一个显著特征。不仅十八、十九世纪的自由主义在退潮，我们从伊拉斯谟与蒙田、从西塞罗与塔西佗、从伯里克利与修昔底德那里承继而来的那种基本的个人主义，也在被逐步放弃。6

那位把民族社会主义革命称为“反文艺复兴”的纳粹头目，恐怕比他自己所知更贴切地说出了事实。这场革命，是对自文艺复兴以来现代人建立起来、并且首先是一种个人主义文明的决定性破坏。今日“个人主义”名声不佳，常被等同于自我与自私。7但这里所说与社会主义及一切形式的集体主义相对立的“个人主义”，并不必然含有这些含义。二者的对照，需在本书进程中逐渐澄清。不过，从基督教与古典哲学所提供的诸要素出发，经由文艺复兴而首次得到充分展开，继而发展为我们所称的“西方文明”的那种个人主义，其要义在于：尊重作为“人”的个体——也就是说，在其自身领域（哪怕这一领域狭小），承认他的见解与趣味具有至高性；并且相信，让人发展各自的天赋与志趣，是可欲的。“自由”“解放”这些词，如今因反复使用乃至滥用而失去光泽，已不太适合用来表达那一时期的理想。“宽容”或许是唯一仍能完整传达那一原则之含义的词——这一原则在整个近代长期占据上风，却在近时再度式微，并于极权国家兴起时彻底消失。

把严格的等第秩序逐步改造为一种人可以至少尝试自主安排人生的状态——使人有机会认识并在不同生活方式之间作出选择——这一变革，与商业的发展紧密相连。自意大利北方的商贸城市起步，这种新的生活观随商业向西北传播，经由法国与德国西南部抵达低地国家与不列颠群岛；凡是没有专制权力扼杀之处，它便扎下了根。在低地诸国与英国，它长期得到最充分的发展，并首次有机会自由成长，成为这些国家社会与政治生活的根基。自十七世纪末与十八世纪起，它又以更成熟的形态向西与向东扩散，传入新大陆，传入欧洲大陆的腹地——此前，那里连年战乱与政治压迫基本湮没了类似萌芽。8

在整个近代欧洲史中，社会发展的总方向，是把个体从那些在日常活动中将其捆束于习俗或成规的绳索中解放出来。对于“个体的自发且不受控的努力能够产生错综复杂的经济秩序”这一事实的自觉体认，只能在这种发展取得一定进展之后才会出现。而对于经济自由的一套自洽论证，则是政治自由所带来的经济活动自由增长的产物——一种无人设计、无人预料的副产品。

或许，释放个人活力的最大成果，就是沿着个人自由的脚步而兴起的惊人科学进步。人类的创造发明力，在更早的时代并不逊色——从那些精巧绝伦的自动玩具与各类机械装置，便可见一斑，尽管当时的工业技术仍停滞不前；又如那几项并未受限于管制的行业（如采矿、制表）的发展。但凡有少数试图把机械发明更广泛地用于工业之举，哪怕有的极为先进，也会立刻遭到扼杀；而只要统治性的观念被当作对所有人具有约束力的信条，求知的欲望就会被压抑：大多数人对何为正当与得体的信念，足以堵住个体创新者的去路。直到工业自由为新知识的自由运用开辟道路——只要能找到愿意自担风险的人，任何想法都可一试，而且常常并非出自那些官方被委以“学术培养”之责的权威体系之内——科学才在过去一百五十年里大步疾行，改变了世界的面貌。

如同常见的情形，我们的文明之本质，往往被它的敌人看得比多数朋友更清楚：那位十九世纪的极权主义先驱奥古斯特·孔德，曾把其称作“西方反复发作的顽疾：个人对整体的反叛”。9诚然，正是这种力量，筑就了我们的文明。十九世纪在前期个人主义上所添加的，不过是使“自由”成为各阶层的自觉，系统而持续地发展此前零星散布的成果，并使其由英、荷两国扩展至欧洲大陆大部。

这番成长的结果，超出了一切预期。凡是撤除了对人类才智自由发挥的藩篱之处，人们便能迅速地满足越来越广泛的欲求。与此同时，生活水平的提升，也使社会中那些黑暗之处愈发刺目，令人难以容忍——尽管几乎没有哪个阶层没有从这般普遍的进步中获得实利。若用我们今日的标准衡量这段惊人的增长，我们便难以公允评价它——因为正是这段增长，造就了今日的标准，如今反过来让许多缺憾显得更明显。要理解它对经历其间的人们意味着什么，我们必须以当初人们的希望与愿望度之：毫无疑问，它的成功超出了人们最狂妄的梦想。到了二十世纪初，西方世界的工人，已获得一种物质上的舒适、生活的安稳与个人的独立，这在一百年前几乎不可想象。

在未来，人们或许会把这份成功最重要、最深远的影响，看作是这样一种新意识：人们对自身命运的掌控感，以及对改善自身处境的无限可能的信念。这种成就感滋生了雄心——而人理应胸怀雄心。原本令人鼓舞的承诺，似乎已不够；进步的速度，似乎太慢；那些曾经让进步成为可能的原则，开始被看作是更快前进的障碍，令人不耐，亟欲扫清。

自由主义的根本原则，绝非要把它变成一套一成不变的静态教条；它并不提供一揽子的铁律。那条基本原则——在安排我们的事务时，应尽量发挥社会的自发力量，尽量少诉诸强制——可以有无穷无尽的具体运用。尤其需要分清的是：有意识地创设一种制度，使竞争能够尽可能地产生良性作用，和对既有制度消极听任，两者大相径庭。也许没有什么比某些自由主义者对若干“经验法则”的木讷坚持——尤其是对“自由放任”原则的固执——更伤害自由主义的事业了。然而，从某种意义上说，这样的姿态既必要又难以避免。面对不计其数的利益群体——它们总能证明某项措施会给一些人带来立竿见影的好处，而其造成的损害却更为间接且难以看见——如果没有某种“硬杠杠”，几乎不可能抵挡住。既然有力的“工业自由”推定无疑已确立，把它包装成“毫无例外”的规则的诱惑，就很难总是抵御得住。

但正因为如此，一旦这种立场在某些点上被突破，整个体系几乎不可避免地迅速崩塌。自由主义的处境还因另一事实而式微：它推动自由社会制度框架渐进改良的进度，注定是缓慢的。这种进步，依赖于我们对那些社会力量及其最佳运行条件的逐渐理解。由于任务是要协助并在必要时补充它们的运作，首要前提便是理解它们。自由主义者对待社会的态度，正如园丁对待他所侍弄的植物：要想营造最有利于其生长的条件，他就必须尽可能了解它的结构与运作方式。

任何明智之人都不该怀疑：十九世纪那几条用以表述经济政策原则的粗疏“规则”，不过是起步——我们还有太多东西要学，沿着既有方向仍有巨大的提升空间。可这种提升，只能随我们对所依赖力量的认识加深而来。有许多显而易见的任务（譬如对货币制度的把握、对垄断的防范或规制），也有更多不那么显眼却同样重要的领域等待开垦；在这些领域，政府都握有足以行善亦可作恶的巨大权力。完全有理由期待：随着对问题理解的加深，我们终有一天能更好地运用这些权力。

然而，向所谓“积极”作为迈进的速度，注定是缓慢的；在短期改良上，自由主义只得在很大程度上倚赖自由带来的财富渐增。与此同时，它不断要与那些可能危及这类进步的主张对抗。渐渐地，它被视为一种“消极”的信条，因为它能给具体个人提供的，往往不过是“共同进步”的一份份额——而这份共同进步，越来越被人们视为理所当然，不再被认作自由政策的成果。甚至可以说，自由主义的成功，恰恰成了它衰落的原因。正因为已经取得的成就，人们愈发不愿容忍那些仍然存在的弊端；这些弊端在今日看来既难忍，也似乎并非不可避免。10

由于对自由政策缓慢推进的焦躁不耐，对那些借自由主义话语为反社会特权辩护之人的正当怒火，以及被既有物质改善所激发出的无限雄心，到世纪之交时，人们对自由主义基本信条的信仰，日益式微。已经得到的，被看作牢固而不可朽坏、一次到位的财产。人们的目光牢牢盯在新的诉求上；而坚持旧原则，似乎成了阻碍这些诉求迅速满足的拦路虎。越来越多人认为，进一步的进步，不可能在那套曾经使过去的进步成为可能的总体框架内实现，而只能靠对社会进行彻底重塑。这已不再是对现有机器加装或优化的问题，而是要把它彻底报废，另起炉灶。随着新一代的希望集中到一个“全新”的东西上，公众对于既有社会如何运作的兴趣与理解迅速下降；而随着对自由体系运作方式的理解衰退，我们对有赖其存在而成就的一切的自觉，也在同步消退。

这里不展开讨论：这种观念变迁如何是由对技术问题的专注所养成的思维习惯不加批判地搬用到社会问题上，以及自然科学家与工程师的思维习惯如何在此过程中贬抑了不合其偏见的既有社会研究成果，并把某种组织理想强加于一个并不适用的领域。11此处我们只想表明：我们的社会观念，是如何完全地、尽管是逐步且几乎难以察觉地，发生了变化。在这一进程的每个阶段，原本看似只是程度之差的东西，累积起来，已造成自由主义旧有社会观与当下社会问题处理方式之间的根本断裂。这种变化，等同于我们在前文所描绘的历史趋势上的彻底倒转：对缔造西方文明的个人主义传统的全盘舍弃。

按照如今占上风的观点，问题不再是：我们如何才能最充分地利用自由社会中存在的自发力量。事实是，我们已着手放弃那些会产生“不可预见”结果的力量，试图以集体的、经过“自觉设计”的指令，来取代市场这种非人格、匿名的机制，从而把一切社会力量导向有意选定的目标。要说明这种差别，引用一本备受推崇的著作中的极端表述，最为贴切。该书鼓吹所谓“为自由而计划”的方案，我们稍后还会多次评述。卡尔·曼海姆博士写道：“我们从未像今天被迫对社会所做的那样，建立并指挥整套‘自然’系统。……人类正越来越倾向于把整个社会生活纳入规制之中，尽管它从未尝试过创造第二自然。”12

值得注意的是，这一思想潮流的逆转，与理念在空间传播方向的逆转相呼应。两个多世纪来，英国的思想向东传播。英国所实现的自由法则，似乎注定要席卷全球。到大约1870年，这股思潮的势力范围，或许已扩展至最东端。自那以后，它开始收缩；另一套并不新鲜、实则古老的思想，从东方卷土重来。英国在政治与社会领域丧失了思想领导权，转而成为“思想的进口国”。此后六十年间，德国成了那些注定会支配二十世纪世界的思想的中心，其影响东西并进。无论是黑格尔还是马克思，是李斯特（Friedrich List）还是施莫勒，是宗巴特还是曼海姆，是更为激进的社会主义，还是低一度的“组织化”“计划化”，各式德国思想无不被各地热情引进，德国的制度也频遭仿效。13

虽然多数新观念（尤其是社会主义）并非发源于德国，但正是在德国，它们得到完善；并在十九世纪末叶至二十世纪前四分之一世纪里，达到最充分的发展。如今，人们常常忘了：在这一时期，德国无论在社会主义理论还是实践上，都有多么显著的领先优势。早在社会主义在此地成为严肃议题的一代人之前，德国议会里就已经有了庞大的社会民主党。直到不久之前，社会主义学说的发展几乎完全由德语世界主导；以致今日俄罗斯的论战很大程度上仍是在接续德国人留下的线索。大多数英美社会主义者至今还意识不到：他们刚刚开始“发现”的诸多问题，早在很久以前就已为德国社会主义者所详论。14

德国思想家在那段时期之所以能对全球施加强大的影响力，不仅因为德国物质上的迅猛进步，更因为在此前的一百年里，德国思想家与科学家赢得了非同寻常的声望——在那时，德国再度成为共同的欧洲文明不可或缺、甚至居于领先地位的一员。但不久，这股影响力便开始为从德国向外扩散的、以颠覆该文明根基为旨归的观念所利用。德国人自己——至少那些传播这些观念的人——非常清楚这种冲突：对他们而言，早在纳粹之前，欧洲文明的共同遗产，便已被重新冠名为“西方文明”（Western）——“西方”不再是旧时“欧陆西部”的地理概念，而是“莱茵河以西”的代名词。从这个意义上说，“西方”的，便是自由主义与民主、资本主义与个人主义、自由贸易以及任何形式的国际主义或爱好和平。

然而，尽管越来越多的德国人对这些“浅薄”的西方理想不屑一顾，甚至正因如此，西方世界的人们仍源源不断地输入德国产的思想；并且被诱导着相信：他们自己过去所坚信的一切，不过是利益的自利化合理化——自由贸易是为英国利益量身打造的教条；英美的政治理想，早已过时，不值一提，甚至值得羞愧。
